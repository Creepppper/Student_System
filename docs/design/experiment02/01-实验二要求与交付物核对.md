## 3. 环境与操作提示（不等于评分硬指标）

- 环境文档要求准备 MySQL/MariaDB、JDK、IDEA/VS Code、Redis/Valkey、Node.js；课件环境是 Windows 视角，当前实际环境可使用 Linux/Windows/macOS，使用 MariaDB/Valkey/Node 24 的等价组合；正式设计不绑定发行版。
- 若依部署文档强调：新增业务表必须创建 **id 主键，类型 int，自动递增**。这条是课程操作要求，概要设计的数据表设计必须遵守。
- 部署文档给出若依前后端部署和代码生成参考链接；当前不执行代码生成，也不创建业务表。
- 参考实例《网上招聘系统概要设计》是六章结构：导言、系统分析、界面设计、体系结构、数据模型、模块设计。其 Struts/JSP/SQL Server 技术不适用于当前 Spring Boot 3 + Vue 3 项目，只参考章节组织。

## 5. 与实验一的关系

实验一已形成四类角色、35 项 P0、11 项 P1、17 个业务数据对象及原型。实验二不重新做需求分析，而是把这些需求映射到真实若依代码和待设计的学生业务模块。  
**因此：**

- 若依现有用户/角色/菜单/日志/代码生成是“基础能力”；
- 学生、班级、班主任任职、考试、成绩任务、发布、学生查询等是“待设计的新业务”；
- 不能把实验一原型截图或概念 ER 当成已运行的业务模块；
- 不能把 `sys_user` 直接当成学生档案。
