## 3. 路由组织

### 3.1 固定路由

`frontend/src/router/index.js` 中 `constantRoutes`：

- `/login`、`/register`、`/401`、`/404`
- `/index` 首页
- `/user/profile/:activeTab?` 个人中心
- `/redirect`、`/lock`

### 3.2 动态路由

- `dynamicRoutes` 中按 `permissions` 定义隐藏详情页（用户授权角色、字典数据、任务日志、代码生成编辑）。
- 登录后 `usePermissionStore.generateRoutes(roles)` 调用 `getRouters()`：
  - `frontend/src/store/modules/permission.js`
  - 后端 `/getRouters` 返回菜单树；
  - `filterAsyncRouter` 把后端 `component` 字符串映射到 `views/**/*.vue`；
  - `Layout`、`ParentView`、`InnerLink` 特殊处理；
  - 动态项通过 `router.addRoute` 注入。

**设计含义：** 学生业务页面不应硬编码到 constantRoutes 主菜单；应通过 `sys_menu` 配置 + `business:*` 权限，沿用动态路由。

## 4. Axios/Token 封装

`frontend/src/utils/request.js`：

- `baseURL = import.meta.env.VITE_APP_BASE_API`；
- 请求拦截器从 `getToken()` 读取 Cookie（`Admin-Token`），加 `Authorization: Bearer <token>`；
- GET 参数序列化；
- POST/PUT 有 5MB/1 秒重复提交保护；
- 响应拦截器统一处理 401、500、601、二进制下载；
- 401 弹窗后调用 `userStore.logOut()`。

`frontend/src/utils/auth.js`：Token 存 Cookie，键 `Admin-Token`。  
`frontend/src/store/modules/user.js`：登录后 `setToken`；`getInfo` 填 roles/permissions；退出清 Token。

> 注意：前端 Token/按钮隐藏只是体验层，后端必须再次校验；不要把前端权限当安全边界。

## 5. 用户管理真实调用链

以 `frontend/src/views/system/user/index.vue` 为例：

```text
用户管理页面
  -> import { listUser } from '@/api/system/user'
  -> listUser(query)
  -> request({ url:'/system/user/list', method:'get', params:query })
  -> Axios baseURL /dev-api (Vite proxy)
  -> Spring Boot: GET /system/user/list
  -> SysUserController.list(SysUser)
  -> ISysUserService.selectUserList(...)
  -> SysUserServiceImpl.selectUserList(...)  [@DataScope]
  -> SysUserMapper.selectUserList(...)
  -> resources/mapper/system/SysUserMapper.xml
  -> MariaDB
  -> TableDataInfo -> Axios -> userList
```

| 层 | 真实文件 | 关键内容 |
| --- | --- | --- |
| 页面 | `frontend/src/views/system/user/index.vue` | `getList()` 调用 `listUser`；表格/查询/新增/编辑/删除/分配角色 |
| API | `frontend/src/api/system/user.js` | `listUser`、`getUser`、`addUser`、`updateUser`、`delUser`、`resetUserPwd`、`changeUserStatus`、`deptTreeSelect` |
| 请求 | `frontend/src/utils/request.js` | Bearer Token、统一错误处理 |
| Controller | `ruoyi-admin/.../system/SysUserController.java` | `@GetMapping("/list")` + `system:user:list` |
| Service | `ruoyi-system/.../service/impl/SysUserServiceImpl.java` | 查询/新增/更新/删除/角色关联 |
| Mapper | `ruoyi-system/.../mapper/SysUserMapper.java` + `resources/mapper/system/SysUserMapper.xml` | SQL |

## 6. 前端权限/菜单要点

- 页面按钮使用 `v-hasPermi="['system:user:add']"` 等指令；
- 菜单来自 `/getRouters`，不是前端写死；
- 角色/权限集合来自 `/getInfo`；
- 路由守卫/用户 store 在登录后加载权限；
- 新增学生业务时：
  - 菜单写入 `sys_menu`（component 指向 `business/...`）；
  - 权限字符串建议 `business:student:*`、`business:score:*`；
  - API 文件放 `frontend/src/api/business/`；
  - 视图放 `frontend/src/views/business/`；
  - 不修改公共 `request.js` 的认证逻辑，不复用 `system:*` 权限。
