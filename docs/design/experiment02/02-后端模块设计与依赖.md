## 2. 现有六模块

| 模块 | 目录 | 职责 | 直接依赖 | 关键类 |
| --- | --- | --- | --- | --- |
| `ruoyi-admin` | `ruoyi-admin/` | 启动、Web Controller、配置 | framework、quartz、generator、MySQL Connector/J | `RuoYiApplication`、`SysUserController` |
| `ruoyi-framework` | `ruoyi-framework/` | Security、JWT、Druid、Redis、MyBatis、AOP | system（common 传递） | `SecurityConfig`、`JwtAuthenticationTokenFilter` |
| `ruoyi-system` | `ruoyi-system/` | 用户/角色/菜单/部门/岗位/字典/参数/通知/日志 | common | `SysUserServiceImpl`、`SysUserMapper` |
| `ruoyi-common` | `ruoyi-common/` | 统一响应、异常、工具、注解、Redis 封装 | 第三方公共库 | `AjaxResult`、`BaseEntity` |
| `ruoyi-quartz` | `ruoyi-quartz/` | Quartz 任务与日志 | common、Quartz | `SysJobController` |
| `ruoyi-generator` | `ruoyi-generator/` | 表导入、Velocity 代码生成 | common、Druid | `GenController` |

**当前统计：6 个现有 Maven 子模块；不是 7 个。**  
`ruoyi-student` 若创建，将成为第 7 个模块，但当前**不计入**。

## 3. 推荐方案：新增 `ruoyi-student`

```text
ruoyi-student/
  pom.xml
  src/main/java/com/ruoyi/student/
    domain/
    mapper/
    service/
    service/impl/
  src/main/resources/mapper/student/
```

### 依赖建议

```text
ruoyi-student
  ├── ruoyi-common        (统一响应/异常/工具/注解)
  └── ruoyi-system        (复用 SysUser/SysRole 等类型，如需账号绑定)
ruoyi-admin
  └── ruoyi-student       (新增依赖；Controller 放 admin)
```

- `ruoyi-student` 不依赖 `ruoyi-framework`，避免反向依赖；
- `ruoyi-framework` 不依赖 `ruoyi-student`，避免框架被业务污染；
- `ruoyi-system` 不依赖 `ruoyi-student`，保持系统管理独立；
- `ruoyi-student` 与 `ruoyi-system` 的耦合仅限必要的账号/角色类型；若需要完全解耦，可只传 ID/DTO。

### Controller 放置

- 建议：`ruoyi-admin/src/main/java/com/ruoyi/web/controller/business/`
- 原因：Controller 属于 Web 接入层；admin 已依赖 framework/student；
- 不把 Controller 放在 `ruoyi-student` 里，避免业务模块引入 Web 层依赖；
- 也可放 `ruoyi-student` 内的 controller 包，但需要额外 Web 依赖；**当前推荐 admin**。

### Spring 扫描

- 启动类 `com.ruoyi.RuoYiApplication` 位于 `com.ruoyi` 根包；
- Spring Boot 默认扫描 `com.ruoyi.**`，因此 `com.ruoyi.student` 会被扫描；
- Mapper 接口使用现有 `@MapperScan`/MyBatis 扫描配置；需确认扫描包包含 `com.ruoyi.student.mapper`；
- 若现有 `@MapperScan` 只列了 `com.ruoyi.**.mapper`，则无需修改；若未覆盖，需在配置中增加包（下一阶段确认）。

### MyBatis XML

- `application.yml` 当前 `mapperLocations: classpath*:mapper/**/*Mapper.xml`；
- 把 XML 放 `ruoyi-student/src/main/resources/mapper/student/` 可被现有 classpath* 规则匹配；
- 无需改变 XML 文件名规则（`*Mapper.xml`）；
- `typeAliasesPackage: com.ruoyi.**.domain` 已覆盖 `com.ruoyi.student.domain`（需启动验证）。

### 事务

- 使用 Spring 现有 `DataSourceTransactionManager`；
- Service 方法使用 `@Transactional(rollbackFor = Exception.class)`；
- 业务审计与成绩/发布变更同事务；
- 不新建数据源/事务管理器。

### 构建影响

- 根 `pom.xml` 增加 `<module>ruoyi-student</module>`；
- `ruoyi-admin/pom.xml` 增加 `ruoyi-student` 依赖；
- 不影响现有六模块的编译；需重新构建全 Reactor；
- 不在本阶段修改 POM，不创建该目录。

## 4. 备选方案：扩展 `ruoyi-system`

| 维度 | 扩展 ruoyi-system | 新增 ruoyi-student |
| --- | --- | --- |
| 修改范围 | 在现有系统模块增加业务包 | 新模块 + admin 依赖 + 根 POM |
| 模块边界 | 系统管理与学生业务混在一起 | 业务边界清晰 |
| 小组协作 | 易冲突 | 可按模块分工 |
| 构建复杂度 | 低 | 增加一个 Maven module |
| 复用类型 | 直接使用 SysUser | 显式依赖 system/common |
| 长期维护 | 系统模块膨胀 | 更利于 P1 扩展 |
| 课程演示 | 简单 | 结构更规范 |
| 风险 | 破坏若依系统模块纯度 | 扫描/Mapper/依赖需验证 |

**推荐：新增 `ruoyi-student`，但标记“待小组评审”**；扩展 `ruoyi-system` 作为后备方案。

## 5. 现有依赖事实

- `ruoyi-admin` 的直接依赖包括 framework、quartz、generator、MySQL Connector/J；
- `ruoyi-framework` 直接依赖 system；common 通过 system 传递；
- `ruoyi-system` 依赖 common；
- `ruoyi-quartz`、`ruoyi-generator` 依赖 common；
- 具体版本见根 POM：RuoYi 3.9.2、Spring Boot 3.5.16、Java 17。
