# 02 模块职责与需求追踪矩阵

> 追踪基准：SRS v1.1-review 的 35 P0 + 11 P1。  
> A=现有若依能力；B=需适配；C=待新建；P1=规划扩展。  
> 表中“计划接口”均为待设计/未实现，不得当作现有 API。

## 2. P0/P1 追踪汇总

| 范围 | 数量 | 覆盖 |
| --- | ---: | --- |
| P0 | 35 | N01～N08 对应的 FR 组；AUTH 由 M01～M03 复用/适配 |
| P1 | 11 | N09 单独；不混入 P0 |
| BR | 122 | 按模块 BR 组引用，未重新编号 |
| DR | 17 + ENT-08 | 现有物理表 0 张学生业务表；全部为概念/规划 |
| 角色 | 4 | 系统管理员/教务/班主任/学生；无任课教师 |

## 3. 主要输入/输出边界

| 模块 | 输入 | 输出/可观察结果 |
| --- | --- | --- |
| N01 | 教务组织维护 | 班级/学年数据；班主任只读本班 |
| N02 | 学生档案/归属/状态 | 学生视图；账号绑定状态 |
| N03 | 教务指派/科目 | 当前任职+历史；任务第一责任人快照 |
| N04 | 考试/范围/科目/满分线 | 考试配置、`EXAM_*` |
| N05 | 班主任本班成绩 | `TASK_*`、成绩记录、三态 |
| N06 | 审核/发布/撤回/更正 | `PUB_*`、版本、审计 |
| N07 | 已发布成绩 | 本人/本班/全校只读结果 |
| N08 | 关键业务事件 | 审计记录、前后值/版本 |
| N09 | P1 申请/导入/趋势/对比 | P1 状态/视图；不改 P0 |

## 5. 覆盖缺口

- 现有若依模块没有学生业务 FR 的实现；M01～M06 只能支撑 AUTH/基础能力；
- N01～N09 全部为规划；没有真实 Controller/Service/Mapper/表；
- 具体 AC/BR 的逐条映射在 SRS 正文；本表按模块组引用，不伪造新 AC；
- P1 的 11 项没有进入 P0 验收。
