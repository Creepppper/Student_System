## 3. 开发环境请求路径

```text
浏览器
  -> http://localhost:3000（Vite，当前未运行）
  -> /dev-api（Vite proxy，开发期）
  -> http://localhost:8080（Spring Boot，当前未运行）
  -> MariaDB :3306 / Valkey :6379（均 active）
```

- `/dev-api` 是开发代理，不是生产必经节点；
- 生产环境应构建 `frontend/dist`，由静态服务器/反向代理提供；
- 不在本阶段选择 Nginx/Docker/云主机，不虚构服务器。

## 5. 运行启动建议

- 启动后端前需要 `DB_PASSWORD`、`TOKEN_SECRET` 等环境变量（不写入文档）；
- 启动前端需要 `npm ci` 和 `npm run dev`；
- 受控启动后验证：`/captchaImage`、`/login`、`/v3/api-docs`、`/swagger-ui.html`；
- 本阶段不启动长期服务、不修改系统配置。

## 6. 端口/防火墙/主机边界

- MariaDB 监听 0.0.0.0:3306 与 IPv6；本项目只使用本机；
- Valkey 监听 127.0.0.1/::1:6379；
- 未验证外部防火墙、域名、证书；
- 不对外暴露数据库/缓存；
- 真实部署前必须补访问控制、备份、日志轮转和密钥管理。
