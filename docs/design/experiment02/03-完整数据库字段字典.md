## 通用约定

- `created_at`、`created_by`、`updated_at`、`updated_by`、`version` 为可变业务表的审计/乐观锁字段；不可变版本/审计表只保留创建字段。
- `created_by/updated_by` 使用 `BIGINT`，与 `sys_user.user_id` 兼容；不建 `sys_user` 物理外键。
- 所有业务主表使用 `id INT AUTO_INCREMENT`；学号、编号、三元组等业务唯一性使用 `UNIQUE`，不以自增 id 代替。
- 0.5 步长同时由 Service 和 `CHECK` 校验；精确满分/线由 Service 对 `stu_exam_subject`/任务快照校验。
- 表名统一 `stu_` 前缀；前缀表示“学生管理业务域”，不表示表里只存学生。
