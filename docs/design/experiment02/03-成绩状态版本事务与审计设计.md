# 03 成绩状态、版本、事务与审计设计

> 依据：SRS 第 3.7～3.9、4.6～4.11、5.5～5.7；不新增状态代码。  
> 本文是逻辑/事务设计，不是已实现代码。

## 1. 三套状态不可合并

| 生命周期 | 合法代码 | 所属表 | 责任角色 |
| --- | --- | --- | --- |
| 考试 | `EXAM_DRAFT`、`EXAM_OPEN`、`EXAM_CLOSED`、`EXAM_ARCHIVED` | `stu_exam.status` | 教务 |
| 成绩任务 | `TASK_DRAFT`、`TASK_SUBMITTED`、`TASK_APPROVED`、`TASK_RETURNED` | `stu_score_task.task_status` | 班主任提交，教务审核 |
| 班级发布 | `PUB_UNPUBLISHED`、`PUB_PUBLISHED`、`PUB_WITHDRAWN` | `stu_publication.publication_status` | 教务 |
| 成绩记录 | `SCORE_NORMAL`、`SCORE_ABSENT`、`SCORE_NOT_ENTERED` | `stu_score.score_status` | 班主任录入 |

**硬约束：**

- `TASK_APPROVED` ≠ `PUB_PUBLISHED`；
- `EXAM_CLOSED` ≠ 已发布；
- `PUB_WITHDRAWN` 不是删除；历史版本保留；
- 不得用 `0` 表示缺考/未录入；
- 不得把 `PUB_*` 塞进 `TASK_*`。

## 2. 成绩三态与精度

| 状态 | `score_value` | 显示 | 提交 | 统计 |
| --- | --- | --- | --- | --- |
| `SCORE_NOT_ENTERED` | NULL | “未录入” | 不允许 | 不参与，学生不可见 |
| `SCORE_ABSENT` | NULL | “缺考” | 允许 | 不进入有效人数/总分分母，不排名 |
| `SCORE_NORMAL` | `DECIMAL(6,1)` 非空 | 分值（0.0 明确显示真实零分） | 允许 | 进入有效人数，按规则参与总分/排名 |

数据库层：

- `DECIMAL(6,1)`，不用 FLOAT/DOUBLE；
- `CHECK`：NORMAL 非空、非负、0.5 步长、防御性上限；ABSENT/NOT_ENTERED 必须 NULL；
- 精确 `<= full_mark_snapshot` 由 Service 对任务快照校验（跨表 CHECK 不可用）；
- Service 与 DB 两层都校验 0.5 步长；
- 统计分母：NORMAL + ABSENT 可提交；ABSENT 不进入有效人数；NOT_ENTERED 阻止提交。

## 3. 任务状态与事务

### 3.1 录入/暂存

```text
锁 task 行（SELECT ... FOR UPDATE）
  -> 校验 task.status ∈ {TASK_DRAFT, TASK_RETURNED}
  -> 校验 exam.status = EXAM_OPEN
  -> 校验当前班主任是 task 的当前有效任职班级
  -> 校验 score.task_id/student_id 属于任务花名册
  -> 校验版本号
  -> upsert stu_score（三态/0.5/满分）
  -> 写 stu_audit_log
  -> commit
```

- 并发冲突返回 409，不静默覆盖；
- 任务提交后为只读；
- 退回后只允许班主任编辑；教务不能代录。

### 3.2 提交

```text
锁 task
  -> 校验 TASK_DRAFT/TASK_RETURNED
  -> 校验 EXAM_OPEN
  -> 校验无 SCORE_NOT_ENTERED
  -> 校验所有记录合法
  -> 校验提交人 ≠ 审核人（若已预分配）
  -> task.status=TASK_SUBMITTED；记录 submitted_by/at；version+1
  -> audit
  -> commit
```

“提交人”和“审核人”是不同账号；多角色账号也按 user_id 比对，不能因为角色合并而自审。

### 3.3 审核

```text
锁 task
  -> 校验 TASK_SUBMITTED
  -> 校验 current_user != submitted_by（强制）
  -> 通过 -> TASK_APPROVED；退回 -> TASK_RETURNED + 原因
  -> 记录 reviewed_by/at/reason；version+1
  -> audit
  -> commit
```

- 退回原因必填；
- 已发布任务要先撤回才能退回（按 SRS）；
- 审核记录保留，不覆盖历史。

## 4. 发布/撤回/更正

### 4.1 发布

```text
锁 exam/class 相关任务
  -> 校验所有适用科目任务 TASK_APPROVED
  -> 校验无 SCORE_NOT_ENTERED
  -> 校验至少一科
  -> 找/建 stu_publication（exam×class 唯一）
  -> 新 version_no = max+1
  -> 插入 stu_publication_version（不可变）
  -> 插入 stu_publication_version_detail（逐学生×科目快照）
  -> publication.current_version_id=新版本；status=PUB_PUBLISHED；published_at
  -> audit
  -> commit
```

- 版本明细是**当时快照**，不引用可变 `stu_score` 作为历史真值；
- `SCORE_ABSENT` 进入明细（值为 NULL），但不进入有效人数/总分分母；
- 发布事务不异步；派生统计可异步重算，但不得用缓存替代真值；
- 失败全回滚，不留下“半发布”。

### 4.2 撤回

```text
锁 publication
  -> 校验 PUB_PUBLISHED
  -> status=PUB_WITHDRAWN；withdrawn_at/reason；version+1
  -> 保留版本/明细
  -> audit
  -> commit
```

- 学生立即不可见；
- 不删除成绩、不删除版本；
- 重新发布需重新校验任务仍 APPROVED，版本 +1。

### 4.3 受控更正

```text
锁 publication + task/score
  -> 校验 PUB_PUBLISHED
  -> 校验教务权限、原因、非自审（如适用）
  -> 更新 score（version 匹配；只能按更正规则）
  -> 新建 version（version_no+1，基于当前版本）
  -> 新 detail 全量快照
  -> current_version_id 指向新版本
  -> status 保持 PUB_PUBLISHED
  -> audit（前后值）
  -> commit
```

- 原版本不可修改/删除；
- 更正后总分/排名按新版本重算；
- 历史版本可追溯。

## 5. 乐观锁

- `stu_score_task.version`、`stu_score.version`、`stu_publication.version` 等 `INT NOT NULL DEFAULT 0`；
- 更新 SQL 带 `WHERE id=? AND version=?`；影响行数 0 → 409 `CONCURRENT_MODIFICATION`；
- 不采用“最后写入覆盖”；
- 版本字段与 publication 的 `version_no` 不同：`version` 是乐观锁，`version_no` 是发布版本号。

## 6. 审计

`stu_audit_log`：

- 事件类型、对象类型/ID/版本；
- `before_data`/`after_data`（应用 JSON，LONGTEXT）；
- 原因、操作人 user_id、角色、时间、来源、trace_id；
- 与业务**同一事务**；审计失败则业务回滚；
- 只插入，不更新/删除；
- 多态引用不建 FK；
- 不存密码/Token/完整敏感个人信息；
- 不能替代发布版本；版本保存快照，审计保存变更事件，两者互补。

**必须审计的动作：**

- 成绩录入/修改/三态变更；
- 任务提交/退回/审核；
- 发布/撤回/更正；
- 学生归属/班主任任职变更；
- 账号绑定/撤销；
- 系统管理员访问敏感元数据（不记录成绩内容）。

## 7. 总分/排名

- 以当前 `publication_version_detail` 为准；
- 完整科目（NORMAL/ABSENT 按规则）才计算总分；
- 缺考不进入有效人数/总分分母；
- 1,2,2,4 竞争排名；
- 更正/撤回/重发后重新计算；
- 不在 P0 建总分/排名表；短 TTL 只读缓存必须按版本键失效；
- 未来物化汇总必须以 `publication_version_id` 关联，不能覆盖历史。

## 8. 事务边界

| 操作 | 同一事务 | 可异步 |
| --- | --- | --- |
| 录入/暂存 | 成绩 + 审计 | 页面统计 |
| 提交/审核 | 任务 + 审计 | 通知 |
| 发布 | 当前发布 + 版本 + 明细 + 审计 | 大屏/报表缓存 |
| 撤回 | 当前状态 + 审计 | 通知/缓存失效 |
| 更正 | 成绩 + 新版本 + 明细 + 审计 | 报表重算 |
| 转班/换班主任 | 关闭旧关系 + 新关系 + 审计 | 通知 |

**禁止：** 先改业务再异步写审计；先删历史再建新版本；用缓存作为成绩/发布真值。
