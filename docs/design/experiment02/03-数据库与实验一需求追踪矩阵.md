# 03 数据库与实验一需求追踪矩阵

> 基线：SRS v1.1-review；35 P0 + 11 P1 + 17 DR + ENT-08。  
> 本表证明“功能 → 数据对象/表/约束”的落点；不新增/改写需求。

## 4. 四类角色一致性

| 角色 | 数据设计 |
| --- | --- |
| 系统管理员 | 账号/绑定/系统表；**无成绩明细授权**；Service 显式拒绝 |
| 教务管理员 | 全部 P0 业务；审核/发布/撤回/更正 |
| 班主任 | 当前有效任职班级；任务/成绩/本班统计 |
| 学生 | 绑定 student_id；本人已发布 |

无任课教师/任教关系。
