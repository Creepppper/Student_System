## 7. Word/WPS 兼容性

**已验证：** LibreOffice 可打开该 DOCX 并重新导出 PDF，说明 OOXML 基本结构、图片和表格可用。

**未验证：** Microsoft Word、WPS 的本机原生打开/另存。不得声称已通过。

人工复核步骤：

1. 用 Word 2016+ 或 WPS 打开 DOCX；
2. 右键目录 → 更新域 → 更新整个目录，核对页码；
3. 检查横向图页方向、页眉页脚、图片是否完整；
4. 检查表格是否可编辑、表头是否重复；
5. 如 Word 中分页与 PDF 略有差异，以最终 PDF 作为提交版，并保留 DOCX 可编辑源。
