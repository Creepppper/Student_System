## 6. 权限/状态冲突检查

| 检查 | 结果 |
| --- | --- |
| 系统管理员无成绩明细 | 正文明确；Service 显式阻断，不依赖 `ALL_PERMISSION` |
| 班主任仅当前任职班级 | 明确，任务/成绩/查询均受范围限制 |
| 学生仅本人已发布 | 明确，身份来自绑定，不接受客户端 studentId |
| 未录入/缺考/零分 | 三态分离，NULL 语义明确 |
| 审核与发布 | `TASK_APPROVED` ≠ `PUB_PUBLISHED` |
| 撤回 | 保留历史，不删除版本 |
| 更正 | 新版本，保留 before/after/审计 |
| P1 | 独立规划，不进入 P0 |
| `sys_user`/`sys_dept` | 不当作学生/班级 |
| 任课教师 | 明确排除 |
