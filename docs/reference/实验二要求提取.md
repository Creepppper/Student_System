## 1. 《实验二.ppt》的明确要求

PPT 标题为“实验二 概要设计的撰写”。正文要求完成以下工作：

1. 体验 RuoYi-Vue 前后端分离架构；
2. 搭建开发环境，下载源码，在本地完成程序运行；
3. 阅读源码并理解软件架构；
4. 参考“网上招聘系统概要设计”撰写概要设计规格；
5. 画出系统架构模块框图；
6. 画出数据库表关系图；
7. 设计前后端接口说明，可以使用 RuoYi-Vue 中的 Swagger 工具生成；
8. 结合 Spring 框架和 RuoYi-Vue 源码说明各模块功能。

PPT给出若依文档、Gitee 仓库和两篇 CSDN 文章作为参考，但没有指定若依分支、Spring Boot 版本或 Vue 版本。“Swagger”在新版 Spring Boot 3 源码中的等价实现是 Springdoc OpenAPI 3，不需要回装 Swagger 2。

## 2. 《第二次实验开发环境准备搭建.docx》

该文档列出的环境是 Windows 教学建议：PhpStudy 管理 MySQL、Navicat、JDK、IDEA、Redis、IDEA 内置 Maven、VS Code 和 Node.js，并写明 Node.js 应不低于 12。它还提醒实验课前准备软件并携带笔记本。

文档没有把 IDEA、PhpStudy 或 Navicat写成验收条件，也没有禁止 Linux、独立 Maven、MariaDB、Valkey 或较新 Node.js。当前 Fedora 方案采用功能等价工具，并通过实际版本、构建和运行证据验收，比复刻旧安装方式更符合实验目标。

## 3. 《若依代码部署、生成与详解.docx》

文档给出一篇部署/代码生成参考文章和一组代码详解文章。唯一明确的数据库约束是：新建表必须创建名为 `id` 的主键，类型为 `INT`，并设置自动递增。本项目把该要求写入 `AGENTS.md` 和生成器使用说明；本次不提前创建学生业务表。

## 4. 《概要设计实例.doc》的可复用结构

该文档是 2006 年的网上招聘系统参考，目录结构如下：

1. 导言：目的、范围、缩写说明、术语定义、引用标准、参考资料、版本更新信息；
2. 系统分析：系统边界、用户和主要功能；
3. 界面设计：按用户端/管理端说明页面和页面流；
4. 体系结构：设计原则、总体体系结构、网络结构、硬件和软件运行环境；
5. 数据模型：概念结构、逻辑结构、物理结构；
6. 模块设计：按模块分别写表示层、控制层和模型/业务逻辑层，并列页面、控制入口出口和模型组件。

可复用的是章节组织、分层说明方法、页面流程、ER 图、表关系图和模块表格。不能照搬的内容包括 Struts、JSP、ActionForm、EJB、ODBC/ADO、SQL Server 2000、Windows 2000、IE 6 和旧硬件指标。当前项目用 Vue 页面/API、Spring MVC Controller、Service、MyBatis Mapper、MariaDB、Valkey 和现代浏览器替代。
