## 7. 检查结论与限制

**通过项**：

- 上下文 4 个外部实体与 FIG-02/02A/02B 一致；
- 8 个 CF 与 32 个外部 DF 双向覆盖；
- P1～P8 无黑箱/奇迹；
- 外部实体不直连存储；
- 认证、权限、审计均有加工/存储/流；
- P1 独立。

**限制/待确认**：

1. FIG-01/FIG-02 的 CF/主题节点是**聚合展示**，不是严格“一条边=一个 DF”；严格逐流对照用本文件第 1、2 节和 `03-数据流与数据存储清单`。
2. FIG-02 的 P2/P3 合并、DS-2/DS-3 主题存储，需在正文/图注中保留解释；局部 FIG-02A/02B 恢复。
3. `DF-106` 保留号未使用；`DF-134` 为可选导出审计（P1 导出时）；不影响 P0 平衡。
4. FIG-02A/02B 是业务局部图，四类登录（DF-021/022/029/030）和班主任审计查询（DF-027/028）只在 FIG-02 总览与 PS-01/PS-13 中表达，未在局部图重复绘制；这是为了避免重复认证/审计边，不代表数据流缺失。
4. 图的可读性/字号限制见 `03-图表视觉与语义检查报告`；建议 A3/横向打印。
