## 4. 与需求规则的对应

- **班主任范围**：`ENT-07/08` + `ENT-04`；`SCOPE_CLASS` 是任职班级集合，**不是**科目授权。
- **历史任务责任**：`ENT-13` 保存班主任第一责任人快照；`ENT-08` 的变更不覆盖历史任务。
- **成绩三态**：`ENT-14` 状态 + 值；缺考/未录入无值，真实零分是 NORMAL+0。
- **发布条件**：`ENT-11/12/13/15`；发布以考试×班级为单位，任务以考试×班级×科目为单位。
- **审计**：`ENT-16` 通过 `entity_type/entity_id` 多态引用任务/成绩/发布等；不画物理外键。
- **P1 复核**：`ENT-18` 关联学生/考试/科目/成绩/班主任；与 P0 状态机隔离。

## 5. 待确认/未决

1. `ENT-08 班主任任职` 无独立 DR 编号，当前作为 `DR-ORG-004` + `DR-TCH-001` 的历史化关联实体；是否在数据库设计中独立成表，待确认。
2. 一名班主任负责多个班时，跨班合并统计/导出是否允许，当前只确认“数据范围=有效任职班级集合”；合并口径待确认。
3. `ENT-16` 审计的多态引用是否使用统一事件表 + 对象类型/ID，还是分表；属物理设计，未决。
4. `ENT-18` P1 复核是否在 P0 数据库中建表，取决于 P1 是否进入实现；当前标记 P1。
5. 科目是否允许“一科多满分方案”未在 ER 展开；当前满分属于考试科目关系（`ENT-12`），不支持同一考试同一科目多方案。

## 6. 结论

- ER 覆盖 17 个 DR 对象，额外把“班主任任职”显式建模为历史化关联实体；
- 班级—班主任、学生—班级归属、任务—成绩、考试—发布的关键基数和唯一性明确；
- 历史任职/归属/任务责任快照不丢失；
- 四类角色、P0/P1 边界、无任课教师均满足 v1.2；
- 物理外键/索引/表名未声明，留待数据库设计阶段。
