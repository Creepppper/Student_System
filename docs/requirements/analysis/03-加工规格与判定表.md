## 2. PS-01 登录与权限解析

**输入**：登录账号、密码、验证码、验证码 UUID。  
**输出**：令牌、角色集合、`business:*` 权限集合、数据范围、登录审计。

1. 校验验证码存在、未过期、匹配；失败则拒绝并刷新。
2. 校验账号存在、启用、密码正确；失败统一提示“账号或密码错误”，不泄露账号存在性。
3. 生成 JWT；加载角色和权限；按角色解析 `SCOPE_SYSTEM/ALL/CLASS/SELF`。
4. 班主任的 `SCOPE_CLASS` = 当前有效任职班级集合；学生 `SCOPE_SELF` = 本人；教务 `SCOPE_ALL`；系统管理员 `SCOPE_SYSTEM`。
5. 记录登录成功/失败审计；停用账号的旧令牌不得继续访问业务接口。

**规则**：功能权限与数据权限同时成立；前端隐藏不作安全边界；内置 `admin` 只用于初始化/应急。

## 3. PS-02 账号-档案绑定

**判定表**：

| 条件 | 结果 |
| --- | --- |
| 账号未绑定，档案未绑定，类型匹配（学生/班主任） | 允许绑定；1:1 |
| 账号已绑定其他档案 | 拒绝 |
| 档案已绑定其他账号 | 拒绝 |
| 学生档案绑定教务/系统管理员角色 | 拒绝（角色与档案类型不匹配） |
| 班主任档案绑定学生角色 | 拒绝 |
| 解绑时存在未完成业务 | 按规则阻止或要求先处理 |

**约束**：账号与档案 1:1；删除/停用账号不删除业务档案和历史成绩。

## 4. PS-03 基础资料与班主任任职

- 学年编码唯一；当前学年最多 1 个；考试、班主任任职必须引用有效学年+学期。
- 班级属于学年+年级；班号/名称在学年内唯一；有学生/成绩后只能归档，不物理删除。
- 学生学号全校唯一；班级归属按学年记录；同一学年最多一条有效归属；转班先结束旧归属。
- 班主任工号唯一；`TCH_ACTIVE` 才能被指派；每班同一时刻最多一条有效任职；1 名班主任可多条任职（多班）。
- 班主任变更：结束旧任职、建立新任职；历史任务第一责任人快照不变；变更审计。
- **语义区分**：`FR-ORG-005` 是班级—班主任指派；已废止的任教关系需求不再存在教师×班级×科目任教关系（见 08 变更记录）。

## 5. PS-04 考试配置

1. 考试属于学年+学期；名称在学年学期内唯一；状态从 `EXAM_DRAFT` 开始。
2. 配置参与班级；班级×适用科目显式配置；不适用科目不生成任务。
3. 每科满分 >0，0.5 倍数、一位小数；及格/优秀线 0～满分、0.5 倍数；默认 60%/85% 可配置。
4. 有任务/成绩后，移除班级/科目/改满分必须拒绝；需先退回/撤回并审计。
5. 开放考试生成任务；结束只关闭录入，不等于发布；归档只读。

## 6. PS-05 成绩任务生成

**唯一键**：考试 + 班级 + 科目。  
**生成条件**：考试为 `EXAM_DRAFT` 且范围/科目/分值完整；班级有有效班主任；花名册有在读学生。  
**生成内容**：任务唯一标识、考试/班级/科目、班主任第一责任人快照、花名册快照、`TASK_DRAFT`、每个学生 `SCORE_NOT_ENTERED`。  
**异常**：缺班主任→阻止开放并提示先指派；重复任务→拒绝；花名册为空→不生成；不适用科目→不生成。

## 7. PS-06 成绩录入与校验

### 7.1 状态/值组合判定表

| 输入状态 | 分数值 | 判定 | 结果 |
| --- | --- | --- | --- |
| `SCORE_NORMAL` | 0～满分、0.5 倍数、一位小数 | 合法 | 保存/统计/排名 |
| `SCORE_NORMAL` | 空 | 非法 | 拒绝；提示填分数或标记缺考 |
| `SCORE_NORMAL` | 负分/超满分/非 0.5 倍数/多位小数 | 非法 | 拒绝；字段级错误 |
| `SCORE_ABSENT` | 空 | 合法 | 保存“缺考”；不参与分母/排名 |
| `SCORE_ABSENT` | 有数值 | 非法 | 拒绝；缺考不得带分 |
| `SCORE_NOT_ENTERED` | 空 | 合法（初始） | 保存未录入；阻止提交/发布 |
| `SCORE_NOT_ENTERED` | 有数值 | 非法 | 拒绝；先选正常或缺考 |
| 真实 0 分 | 0 | 合法 | `SCORE_NORMAL` + 0；参与统计/排名 |

### 7.2 校验算法（结构化）

```
输入：任务 task，学生 student，状态 status，数值 value，版本 version
1. 任务属于当前班主任有效任职班级；否则 403
2. 任务为 TASK_DRAFT/TASK_RETURNED；考试为 EXAM_OPEN；否则拒绝
3. student 在 task 花名册；否则拒绝
4. 若 status = NORMAL:
      value 必须非空、0 <= value <= full_score、value*2 为整数、保留 1 位小数
   若 status = ABSENT: value 必须为空
   若 status = NOT_ENTERED: value 必须为空
5. version 与当前任务版本一致；否则提示刷新，不覆盖
6. 保存；记录修改人/时间；写审计；不改变任务状态
```

**精度**：所有分数/满分/线用定点十进制（如 0.1 分单位或十进制类型）；不用二进制浮点直接比较。

## 8. PS-07 提交前完整性检查

| 条件 | 结果 |
| --- | --- |
| 任务为 `TASK_DRAFT`/`TASK_RETURNED`，考试 `EXAM_OPEN` | 可提交 |
| 存在 `SCORE_NOT_ENTERED` | 拒绝，列出学生 |
| 存在非法分数/缺考带分 | 拒绝，指出字段 |
| 版本号不匹配 | 拒绝，提示刷新 |
| 全部 NORMAL/ABSENT，版本匹配 | 原子更新为 `TASK_SUBMITTED`，记录提交人/角色/时间/快照 |
| 任务已提交/通过/发布 | 重复提交拒绝（或幂等提示） |
| 提交后想撤回 | 不允许；由教务退回 |

## 9. PS-08 教务审核

| 条件 | 结果 |
| --- | --- |
| 任务 `TASK_SUBMITTED`，审核人 ≠ 该任务提交人 | 可通过 |
| 退回 | 原因必填；任务 `TASK_RETURNED` |
| 审核人 = 提交人（含多角色） | 拒绝；记录尝试 |
| 任务非 `TASK_SUBMITTED` | 拒绝 |
| 已发布任务 | 先撤回才能退回 |
| 通过 | 任务 `TASK_APPROVED`；记录审核人/时间 |

**职责分离**：按任务提交人、实际操作人比对，不按“当前选中角色”判断；即使拥有 `SCOPE_ALL`/`A` 也拒绝自审。

## 10. PS-09 班级发布

| 条件 | 结果 |
| --- | --- |
| 该班所有适用科目任务 `TASK_APPROVED` | 可发布 |
| 缺任一适用科目通过 | 拒绝，列出科目 |
| 存在 `SCORE_NOT_ENTERED` | 拒绝，列出学生 |
| 适用科目为空 | 拒绝 |
| 已发布 | 重复发布不产生新版本；需撤回/更正 |
| 发布成功 | `PUB_PUBLISHED`，版本 1；记录发布人/时间/范围 |

## 11. PS-10 撤回/更正

### 11.1 撤回

- 条件：`PUB_PUBLISHED`；原因必填；操作人教务。
- 结果：`PUB_WITHDRAWN`；学生立即不可见；数据保留；版本/审计记录。

### 11.2 更正

| 条件 | 结果 |
| --- | --- |
| 已发布，教务，原因/前后值完整，版本匹配 | 更新成绩/状态；版本+1；重算总分/排名；审计 |
| 班主任/系统管理员/学生 | 拒绝 |
| 原因为空 | 拒绝 |
| 版本冲突 | 拒绝，不静默覆盖 |
| 系统性错误 | 撤回→退回相关任务→更正→重审→重新发布，版本递增 |
| 更正后学生查询 | 看到新分数/排名；审计可还原 |

## 12. PS-11 总分与排名

```
总分仅当该生该考试所有适用科目均为 NORMAL 或 ABSENT（且无 NOT_ENTERED）且成绩完整时计算；
缺考科目不产生分数值，总分标记“不完整”；
完整总分降序；同分竞争排名：1,2,2,4；
缺考/不完整学生不参与排名，单独注明；
P0 只做班级排名，不做年级排名。
```

| 学生 | 总分 | 排名 |
| --- | --- | --- |
| A | 450 | 1 |
| B | 440 | 2 |
| C | 440 | 2 |
| D | 430 | 4 |

## 13. PS-12 单科统计分母

- 分母 = 该考试×班级×科目中 `SCORE_NORMAL` 的有效人数；
- `SCORE_ABSENT` 单列缺考数，不进入分母；
- `SCORE_NOT_ENTERED` 单列未录入数，不进入分母；发布前阻止发布；
- 无有效成绩 → 显示“无有效成绩”，不显示 0%；
- 不同满分不直接混算；P0 不做跨考试趋势/多班对比。

## 14. PS-13 班主任数据范围

```
当前账号的角色含 HEAD_TEACHER
  取 D3 中 结束日期为空或覆盖当前日期的任职记录
  得到有效班级集合 C
  请求中的 classId 必须属于 C；否则 403
  任务/成绩/统计/复核均按 C 过滤
  不在 C 的班级：列表不返回，详情 403/404，导出不包含
```

- 不能通过改 `classId`、`studentId`、分页/导出参数扩大范围；
- 系统管理员/教务/学生不套用本规则；系统管理员仍不看成绩明细。

## 15. PS-14 职责分离（自审）

| 场景 | 判定 |
| --- | --- |
| 教务审核自己作为班主任提交的任务 | 拒绝通过/退回 |
| 教务确认自己申请的复核更正 | 拒绝 |
| 一人多角色（教务+班主任） | 功能权限并集，但不得自审 |
| 无法满足独立审核 | 记录课程项目简化并禁止自审；不得伪造独立审核 |

## 16. PS-15 P1 复核

| 当前状态 | 动作 | 角色 | 下一状态 |
| --- | --- | --- | --- |
| `REV_PENDING` | 撤回 | 学生本人 | `REV_WITHDRAWN` |
| `REV_PENDING` | 受理 | 本班班主任 | `REV_PROCESSING` |
| `REV_PENDING` | 驳回（原因） | 本班班主任 | `REV_REJECTED` |
| `REV_PROCESSING` | 提交核查意见 | 本班班主任 | `REV_PROCESSING`（不改变状态） |
| `REV_PROCESSING` | 确认无需修改 | 教务 | `REV_NO_CHANGE` |
| `REV_PROCESSING` | 确认更正 | 教务 | `REV_CORRECTED`，复用 FR-PUB-004 |
| `REV_PROCESSING` | 驳回 | 教务 | `REV_REJECTED` |

**约束**：同一学生+考试+科目无活跃重复；终态后同成绩版本不再受理；班主任不能直接改分；P1 不改变 P0 状态机。

## 17. PS-16 审计记录

- 关键事件：成绩值/状态变化、任务提交/退回/通过、发布/撤回/更正、考试范围/花名册变更、学生归属变更、班主任变更、复核节点。
- 审计字段：事件类型、对象类型/ID、前后值、原因、操作人/角色、时间、来源。
- 与业务变更同事务写入；只追加；失败则业务回滚或拒绝。
- 可见性：教务业务审计；系统管理员系统/安全审计元数据（成绩字段脱敏）；班主任本班相关；学生不可见。
- 通用接口日志不能替代业务变更记录的前后值。

## 18. 规格自检

- 覆盖 0.5 分步长、缺考/零分/未录入、提交完整性、审核发布、总分、排名、统计分母、班主任范围、自审、更正审计、P1 复核；
- 所有判定表都有明确输入/条件/结果；
- 未写 SQL/Controller/Service；未修改代码或数据库。
