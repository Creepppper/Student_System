# 03 正式数据字典

> 基线：`BL-REQ-001 v1.2-provisional`  
> 阶段：第 3 阶段结构化分析  
> 范围：数据元素、数据流、数据存储、外部实体、加工、业务状态。  
> 说明：本文是**业务数据字典**，不是数据库表结构；不声明物理外键、索引或 SQL。  
> 元素/流/存储编号与 [03-数据流与数据存储清单](03-数据流与数据存储清单.md) 一致。

## 1. 记法

- `DE-`：数据元素；`DF-`：数据流；`D`：详细存储；`DS-`：1 层主题存储；`P`：加工；`EO-`：外部实体。
- 类型用业务类型描述：标识、文本、枚举、整数、定点小数、日期时间、布尔、集合、快照。
- “必填”指业务上不能为空；“可空”不等于可随意缺失，需由状态/规则决定。
- 0.5 分步长、一位小数、定点十进制比较；禁止二进制浮点直接比较。
- 缺考/未录入的分数值必须为空，不能用 0 代替；真实 0 分是 `SCORE_NORMAL` + 0。

## 8. 字典完整性自检

- 46 个数据元素（DE-001～046）；覆盖认证、权限、组织、人员、考试、任务、成绩、发布、审计、复核、统计；
- 8 个 CF、32 个外部 DF、34 个内部 DF（DF-101～135，DF-106 保留）、12 个 P1 DF；与图形/清单编号一致；
- 9 个详细存储、4 个主题存储、4 个外部实体、8 个加工、28 个状态；
- 每个 DF 至少关联一个 FR/DR；每个 D 有主键/唯一性/约束；
- 无任课教师、任教关系、`SCOPE_ASSIGNED`；P1 复核独立；
- 不声明物理表、外键、索引或 SQL。
