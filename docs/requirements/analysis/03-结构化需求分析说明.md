## 1. 分析目标与边界

本阶段把 v1.2 的文字需求转换为**结构化分析模型**：

- 系统上下文与 1 层 DFD；
- 功能模块分解；
- 业务概念 ER；
- 数据流、数据存储、数据元素、加工规格字典；
- DFD 层次平衡与 ER 关系检查；
- 图表视觉与语义检查；
- 结构化模型到 FR/BR/DR/UC/AC 的追踪。

**不包含**：UML 类图/时序图、页面原型、Word 定稿、数据库物理设计、Java/Vue/SQL 实现。

## 2. 现行口径

| 项 | 口径 |
| --- | --- |
| 系统 | 单所高中、单套部署；不做多校/多租户 |
| 角色 | 系统管理员、教务管理员、班主任、学生（四类） |
| 数据范围 | `SCOPE_SYSTEM` / `SCOPE_ALL` / `SCOPE_CLASS` / `SCOPE_SELF` |
| 教师端 | 只保留班主任；**不设任课教师、任教关系、`SCOPE_ASSIGNED`** |
| P0 | 35 项功能；主链路：基础资料→考试配置→成绩录入/提交→审核发布→学生查询→业务审计 |
| P1 | 11 项功能；复核、导入导出、趋势、班级对比；不进入 P0 退出条件 |
| 成绩任务 | 考试×班级×科目唯一；责任人为班主任 |
| 成绩精度 | 0.5 分步长、一位小数、定点十进制 |
| 缺考/未录入/零分 | 三态分离；缺考/未录入无值；真实零分是 `SCORE_NORMAL` + 0 |
| 审核发布 | 教务审核/退回/发布/撤回/更正；班主任不能审核自己提交的任务 |
| P1 复核 | 学生→班主任受理并核查→教务确认/更正→学生查看 |

## 3. 建模方法

1. **自顶向下**：先画上下文（FIG-01），再分解 1 层（FIG-02），对成绩/发布/认证等复杂部分用 FIG-02A/02B 局部展开，P1 用 FIG-02C 独立扩展。
2. **数据流与存储分离**：DFD 只表达数据流、加工和逻辑存储，不画 Controller/Service、不画操作步骤。
3. **概念 ER**：只表达业务实体、联系、基数与约束；不声明物理外键或数据库已实现。
4. **数据字典**：外部实体、加工、数据流、数据存储、数据元素、状态分别编号，并与 FR/BR/DR 关联。
5. **加工规格**：对 0.5 分步长、缺考/零分/未录入、提交完整性、审核发布、总分/排名、统计分母、权限、自审、更正审计等给判定表/结构化文字。
6. **追踪**：每个 FR 至少落到一个加工、一个数据流/存储、一个 ER 实体和验收场景。

## 6. 核心模型说明

### 6.1 系统边界

系统边界内：身份认证与权限、基础资料、考试配置、成绩任务/录入/提交、审核发布、查询统计、业务审计；P1 复核/导入/趋势/对比是扩展。

系统边界外：四类业务用户；MariaDB/Valkey 是技术基础设施，**不是 DFD 外部实体**；若依是复用基础能力，不画成外部实体。

### 6.2 加工分解

- **P1 身份认证与权限**：登录、令牌、角色/权限、数据范围、账号绑定、登录审计。
- **P2 基础资料**：学年/学期/年级/班级/学生/班主任档案/科目/班主任任职。
- **P3 考试配置**：考试、范围、适用科目、满分/线、状态。
- **P4 成绩录入与提交**：任务读取、本班全科录入/暂存、校验、完整性检查、提交、退回重提。
- **P5 审核发布**：逐任务审核/退回、按考试×班级发布、撤回、受控更正。
- **P6 查询统计**：学生本人已发布、班主任本班、教务全校、总分/排名/单科统计。
- **P7 业务审计**：审计事件写入、按权限查询、脱敏。
- **P8（P1）复核**：申请/时限、班主任受理并核查、教务确认/更正、学生查看。

### 6.3 数据存储

D1 账号与权限、D2 组织与人员、D3 班主任任职、D4 考试配置、D5 成绩任务、D6 成绩记录、D7 成绩发布、D8 业务审计；P1 另有 D9 复核申请。

FIG-02 为可读性使用主题存储 `DS-1`～`DS-4`：DS-1=D1，DS-2=D2+D3+D4，DS-3=D5+D6+D7，DS-4=D8；局部图恢复 D1～D8。

### 6.4 ER 核心

17 个 DR 对象对应 17 个 ER 实体；`ENT-08 班主任任职`是历史化关联实体，不新增 DR；`ENT-18 复核申请`是 P1 扩展。关键约束：

- 班级 1:N 班主任任职；每班最多 1 条有效任职；班主任 1:N 任职（可多班）。
- 学生 1:N 班级归属；同一学年最多 1 条有效归属；历史保留。
- 考试×班级×科目唯一任务；任务×学生唯一成绩。
- 考试×班级唯一发布，版本递增。
- 账号与档案 1:1；审计多态引用；P1 复核独立。
