## 3. 类图多重性检查

| 关联 | 修正后 | 说明 |
| --- | --- | --- |
| 班级—成绩任务 | `1 : 0..*` | 1 班 N 任务；每任务 1 班 |

| 班级—班级归属 | `1 : 0..*` | 归属历史 |
| 成绩任务—成绩记录 | `1 : 0..*` | 任务×学生唯一 |

## 4. 活动流程闭环检查

| 图 | 闭环 |
| --- | --- |
| FIG-07 | 正常：创建/配置→生成→录入→系统校验→提交→审核→发布→学生查询；异常调用 07A/07B，不提前结束正常活动 |
| FIG-07A | `repeat`：非法值修正 / 未录入补录 → 重新校验；直到合法且无未录入，保留 TASK_DRAFT 可提交 |

| FIG-07C | 撤回→PUB_WITHDRAWN→学生不可见；重发要求全部任务 APPROVED、版本+1 |

**泳道**：教务创建/审核/发布/撤回/更正；系统校验/状态/排名/权限；班主任录入/修改/提交；学生只查询本人已发布。  
**终结**：异常子活动独立终结；主图通过调用行为动作交接，不使用跨整张画布的长线；`detach` 仅用于转入子活动。
