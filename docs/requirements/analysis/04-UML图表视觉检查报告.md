## 2. 字体/符号

- 字体：`Noto Sans CJK SC`；中文正常。
- 用例：Actor 火柴人、系统边界矩形、椭圆用例、普通实线关联（不再使用带方向箭头）；未使用 include/extend；未使用 Actor 泛化。
- 类图：UML 类框、属性、关联和多重性；P1 紫色 `<<P1>>`；无 Controller/Service/Mapper。
- 状态图：初始/终态、状态、带角色/事件/守卫的转换；状态代码来自基线。
- 活动图：泳道、开始/结束、决策/合并、调用行为动作；无 API 端点。
