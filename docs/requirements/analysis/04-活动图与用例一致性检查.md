# 04 活动图与用例一致性检查

> 用例：UC-EXAM-001、UC-SCORE-001/002、UC-PUB-001/002/003、UC-QUERY-001  
> 图：FIG-07 主链路、FIG-07A 异常/退回/撤回  
> 结论：**P0 主/备选流程覆盖；四类职责泳道正确；未出现后端 API/DFD 复刻；P1 未混入。**

## 1. FIG-07 主链路步骤

| 步骤 | 泳道 | 对应用例/规则 |
| --- | --- | --- |
| 创建考试、配置范围/科目/满分线、开放考试 | 教务 | UC-EXAM-001；EXAM_DRAFT→OPEN |
| 按考试×班级×科目生成任务 | 系统 | UC-SCORE-001 前置；任务唯一 |
| 录入/暂存本班全科成绩 | 班主任 | UC-SCORE-001；本班全科 |
| 数据合法性检查；非法→提示/修正/进入异常处理 | 班主任 | UC-SCORE-001；步长/数值规则 |
| 未录入检查；存在→阻止提交、列出学生、补充 | 班主任 | UC-SCORE-002；未录入不得提交 |
| 提交成绩任务 | 班主任 | UC-SCORE-002；EXAM_OPEN/版本匹配 |
| 逐任务审核；不通过→退回并填原因 | 教务 | UC-PUB-001；职责分离 |
| 修改后重新提交/重新审核 | 班主任/教务 | UC-SCORE-002/UC-PUB-001；退回重提 |
| 按考试×班级发布 | 教务 | UC-PUB-002；所有任务 APPROVED |
| 查询本人已发布成绩 | 学生 | UC-QUERY-001 |
| 撤回→成绩不可见（数据保留） | 教务/学生 | UC-PUB-003；PUB_WITHDRAWN |

## 2. FIG-07A 异常/退回/撤回步骤

| 分支 | 处理 | 结果 |
| --- | --- | --- |
| 数据非法 | 提示字段/步长错误→修正→重新校验 | 不提交 |
| 存在未录入 | 阻止提交→列出学生→补充→重新校验 | 不提交 |
| 审核不通过 | 退回并填原因→修改后重新提交→重新审核 | 可继续审核 |
| 发布成功 | 学生可查询 | P0 正常 |
| 教务撤回 | 撤回并填原因→学生不可见、数据保留 | 可重新发布 |
| 无需撤回 | 学生保持可见 | P0 正常 |

> 主图对非法/未录入分支用“进入异常处理/见 FIG-07A”表示交接，07A 展开处理；这不是把异常静默结束，也不是删除分支。
