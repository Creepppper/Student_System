# 04 状态机与业务规则检查

> 基线：`BL-REQ-001 v1.2-provisional`；状态字典：`04-核心业务规则.md` 第 2～3 节  
> 图：FIG-06（任务）、FIG-06A（发布）、FIG-06B（考试）  
> 结论：**三个生命周期分离；状态代码未新增；TASK_APPROVED 与 PUB_PUBLISHED 未混用；不出现无来源状态。**

## 1. 为什么拆成三张状态机

考试、成绩任务、班级发布是三个独立生命周期：

- 考试 `EXAM_*`：配置窗口/录入窗口/归档；
- 任务 `TASK_*`：提交、审核、退回、重提；
- 发布 `PUB_*`：班级级发布、撤回、重发、版本更正。

`EXAM_CLOSED` 只表示录入窗口关闭，**不等于发布**；`TASK_APPROVED` 只表示任务可参与发布，**不等于 `PUB_PUBLISHED`**。一张图混画会产生虚假的跨生命周期转换，因此拆为 FIG-06/06A/06B。

## 2. FIG-06 成绩任务生命周期

| 源状态 | 事件/角色 | 目标状态 | 守卫 |
| --- | --- | --- | --- |
| 初始 | 系统 / 生成任务 | `TASK_DRAFT` | 考试×班级×科目唯一 |
| `TASK_DRAFT` | 班主任 / 提交 | `TASK_SUBMITTED` | `EXAM_OPEN`；无未录入；数值合法；版本匹配 |
| `TASK_SUBMITTED` | 教务 / 审核通过 | `TASK_APPROVED` | 审核人≠提交人；成绩合法 |
| `TASK_SUBMITTED` | 教务 / 退回 | `TASK_RETURNED` | 原因必填 |
| `TASK_APPROVED` | 教务 / 退回 | `TASK_RETURNED` | 原因必填；班级未发布 |
| `TASK_RETURNED` | 班主任 / 重新提交 | `TASK_SUBMITTED` | 无未录入；数值合法；版本匹配 |

**检查**：

- 未录入阻止提交：通过（`TASK_DRAFT`→`TASK_SUBMITTED` 守卫）；
- 提交后班主任不能自行撤回：通过（图注 + 无 `SUBMITTED→DRAFT` 转换）；
- 审核前职责分离：通过（`审核人≠提交人`）；
- 退回后重提：通过；
- 不把 `TASK_APPROVED` 画成发布：通过。

## 3. FIG-06A 班级发布生命周期

| 源状态 | 事件/角色 | 目标状态 | 守卫 |
| --- | --- | --- | --- |
| 初始 | 系统/教务 | `PUB_UNPUBLISHED` | 班级×考试唯一 |
| `PUB_UNPUBLISHED` | 教务 / 发布 | `PUB_PUBLISHED` | 所有适用任务 `TASK_APPROVED`；无未录入；至少 1 科 |
| `PUB_PUBLISHED` | 教务 / 撤回 | `PUB_WITHDRAWN` | 原因必填 |
| `PUB_WITHDRAWN` | 教务 / 重新发布 | `PUB_PUBLISHED` | 所有任务仍 `TASK_APPROVED`；版本+1 |
| `PUB_PUBLISHED` | 教务 / 受控更正 | `PUB_PUBLISHED` | 原因；前后值；生成新不可变版本；旧版本不覆盖；重算总分/排名 |

**检查**：

- 发布是班级级动作，不是任务级：通过；
- 撤回后学生不可见：通过（图注：数据保留）；
- 发布后不能直接覆盖：通过（只有受控更正自环；保持 PUB_PUBLISHED；生成新不可变版本，旧版本/原值/新值/原因/操作人/时间保留）；
- 撤回/更正/重发写审计：通过。

## 4. FIG-06B 考试生命周期

| 源状态 | 事件/角色 | 目标状态 | 守卫 |
| --- | --- | --- | --- |
| 初始 | 教务 | `EXAM_DRAFT` | 创建考试 |
| `EXAM_DRAFT` | 教务 / 开放考试 | `EXAM_OPEN` | 至少 1 班、至少 1 科、满分>0 |
| `EXAM_OPEN` | 教务 / 结束录入 | `EXAM_CLOSED` | 不要求全部提交 |
| `EXAM_CLOSED` | 教务 / 重开 | `EXAM_OPEN` | 必须填原因 |
| `EXAM_CLOSED` | 教务 / 归档 | `EXAM_ARCHIVED` | 无 `TASK_DRAFT/SUBMITTED/RETURNED` |
| `EXAM_ARCHIVED` | — | 终态 | 已发布成绩仍可查 |

**检查**：状态转换只由教务执行；`EXAM_ARCHIVED` 终态；`EXAM_CLOSED` 不等于发布；未新增状态。
