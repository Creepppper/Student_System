## 4. 关系语义检查

| 检查 | 结果 |
| --- | --- |
| 是否使用 include/extend | **未使用**；没有需求确认的强制包含/扩展 |
| 是否使用 Actor 泛化 | **未使用**；四类角色是并列业务角色 |
| 系统边界 | 四类 Actor 均在系统矩形外 |
| 技术组件 Actor | 无；数据库/缓存/若依组件不是 Actor |
| 任课教师 | 无 Actor、无“任教”关系、无按科目授权 |
| 每个重要用例 UC/FR | 表中逐项给出；P1 紫标 |
| P0/P1 混用 | 无；P1 不进入 P0 退出条件 |

## 5. 细节说明

- 班主任用例只覆盖本班全部适用科目，不设“任课教师录入自己科目”。
- 教务用例不包含“代替班主任录入”；审核人不能是提交人（见 FIG-06/06A）。
- 学生用例只读本人已发布成绩；撤回/未发布/未录入状态不可见（FIG-07/07A、FIG-06A）。
- 系统管理员的审计查询默认脱敏，不默认查看成绩明细。
- 用例图中的“登录”是支持用例，不改变业务目标层级。
