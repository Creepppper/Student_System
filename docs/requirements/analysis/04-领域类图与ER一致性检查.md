## 5. 与 ER 的差异与理由

| 差异 | 理由 |
| --- | --- |
| FIG-05 省略 `学期/科目/考试范围/账号/审计` | 总览只保留核心；局部 05A/B/C 完整 |
| FIG-05 将 `班级—学生`、`班主任—班级` 画成当前关联 | 避免总览线过多；历史化关联在 05A 精确定义 |
| FIG-05B 不画 `班主任` 类 | 任务通过 `primaryTeacherId` 快照引用；班主任类及任职在 05A/05D |
| FIG-05C/05D 拆分发布与 P1 | 避免一张局部图同时画发布、审计、复核，减少交叉；P1 不混入 P0 |

**结论**：未发现概念类与 ER 的结构冲突；总览的简化关系已在局部图中恢复精确多重性，可作为后续详细设计的业务概念基础。
