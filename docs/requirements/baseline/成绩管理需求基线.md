# 高中理科班成绩管理需求基线

版本：1.0（阶段一至七实现后的确认版）
日期：2026-11-14
状态：由开发过程中已确认的规则整理而成；若需变更，先修改本文件，再修改代码与测试。

## 1. 范围

本基线覆盖：学生信息、考试信息、学生成绩、查卷申请、成绩统计（考试排名、学生成绩单、班级平均分）、班主任负责班级、学生端（我的成绩、我的查卷、提交查卷）、学生 Excel 导入。

不在范围内：课程、教师独立档案、高考预测、成绩 Excel 导入、班级统计以外的图表。

## 2. 角色与数据范围

| 角色 | 标识 | 数据范围 | 主要功能 |
|---|---|---|---|
| 超级管理员 | admin | 全部 | 全部功能，包括学生导入、班主任分配、账号绑定 |
| 班主任 | teacher | 负责班级（年级 + 班级）的学生、成绩、查卷 | 录入成绩、处理查卷、排名与统计（仅本班） |
| 学生 | student | 绑定到本账号的学生记录 | 查看本人成绩单与名次，提交查卷申请 |

- 学生账号必须在学生信息中绑定；一个账号只能绑定一个学生，一个学生只能绑定一个账号。
- 登录页可自助注册学生或班主任账号，管理员角色不能自助注册；注册后由管理员绑定学生档案或分配班主任负责班级。
- 学生登录后默认查看本人基本信息，包含姓名、学号、年级、班级和所分配的班主任；未绑定或未分配班主任时显示相应提示。
- 绑定的账号必须拥有“学生”角色且处于启用状态；未绑定的学生账号看不到任何成绩。
- 班主任的负责班级在“班主任班级”中分配。同名班级在不同年级视为不同班级。
- 一个年级班级最多分配一名班主任；一名班主任可以负责不同年级的多个班级。
- 没有班级分配的班主任看不到任何学生数据。
- 年级固定为“高一”“高二”“高三”；各年级班级固定为“1班”至“12班”。新增、修改和导入均拒绝范围外或非标准名称。
- 数据范围在后端强制执行：列表按范围过滤，单条读写前逐条校验。前端按钮隐藏只是辅助。

## 3. 科目与满分

| 科目 | 代码 | 满分 |
|---|---|---|
| 语文 | chinese | 150 |
| 数学 | math | 150 |
| 英语 | english | 150 |
| 物理 | physics | 100 |
| 化学 | chemistry | 100 |
| 生物 | biology | 100 |

- 分数可保留两位小数，范围 0 至满分。
- 未录入用 NULL 表示，不参与总分与排名。
- 缺考：该科成绩记为 0，缺考代码写入 `absent_subjects`（逗号分隔，不带空格）。缺考科目的成绩非零时拒绝保存。
- 同一学生在同一考试中只能有一条成绩。
- 成绩管理按一次考试展示，默认选择名称为“2026春期中考试”的考试；若该考试不存在，提示用户选择考试。

## 4. 成绩计算与排名

- 总分：六科之和。只有六科均已录入（缺考计 0）的记录才有总分，并参与排名。
- 排名范围：年级排名（同一年级内）、班级排名（同一年级同一班级内）。排名依据为总分或单科。
- 同分并列同一名次，下一名次顺延（1、1、3）。
- 年级为必选；班级排名时班级也为必选。不同年级、班级的学生不会放在同一个排名中。
- 成绩单：学生历次考试的六科成绩，附该次考试的年级名次和班级名次；成绩未完整的记录标注“未完整”，不显示名次。
- 班级平均分：只统计六科齐全的学生，平均值保留两位小数，缺考按 0 分计入。
- 排名与统计目前在 Java 中计算，不落库；设计文档中原计划的窗口函数方案未采用，原因是需要在本地数据库完整验证，已记录在阶段三的说明中。

## 5. 查卷申请

- 状态：待处理 → 已受理 → 已完成；待处理或已受理可以驳回；已驳回、已完成为终态。
- 受理时处理意见可选；驳回、完成时必须填写处理意见（最长 500 字）。
- 状态只能通过处理接口修改，通用新增与修改不能改变状态；修改只允许待处理的申请。
- 并发处理采用条件更新，后提交者收到“状态已被他人修改”。
- 学生提交查卷：学生由登录账号决定；考试、科目必须存在；该学生在该考试中须有成绩记录；同一科目已有待处理或已受理的申请时拒绝重复提交。
- 已处理的申请可以删除（不设删除限制）。

## 6. 删除保护

- 有成绩记录或查卷记录的学生不能删除。
- 有成绩记录或查卷记录的考试不能删除。
- 已绑定学生的系统账号不能删除，需先在学生信息中解除绑定。

## 7. 导入

- 学生 Excel 导入仅管理员可用，列为：学号、学生姓名、年级、班级名称。
- 学号重复：默认跳过；勾选“更新”时覆盖姓名、年级、班级，但保留已绑定的账号。
- 导入不设置账号绑定。
- 单行失败不影响其他行，结果逐行说明。成绩的 Excel 导入不在本版范围。

## 8. 演示数据

- `database/009_demo_students_scores.sql` 提供虚构的学生与成绩，仅用于演示和测试，不得在正式数据上执行。

## 9. 已采用的默认值（待确认）

以下规则是开发时采用的默认值，如需调整请修改本文件：

1. 查卷：已受理的申请可以驳回。
2. 排名：六科不全的学生不参与排名。
3. 并列名次：采用 RANK 语义（1、1、3）。
4. 班主任权限：按班级（年级 + 班级），不按年级。
5. 分数精度：允许两位小数。
