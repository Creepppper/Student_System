## 0. 文档说明

1. 本文件以基线 `BL-REQ-001 v1.2-provisional` 为准；FR/BR/D 编号沿用基线，不重排。
2. P0 是第一条可演示、可验收主链路；P1 是 P0 稳定后的增强，**不并入 P0 必须完成的交付条件**。
3. 本文只描述系统应表现出的外部行为，不规定数据库表、接口 URL、Java/Vue 类或页面组件。
4. 当前仓库只有若依基础能力，本文件所有业务功能均为**目标能力、尚未实现**。
5. 来源中的“课程场景/课程 PPT”是课程材料依据，不是真实学校访谈；未伪造访谈或评审。
6. 每条 P0 需求均给出主验收场景 `AC-<FR>`，详细验收见 `02-需求验收标准.md`。

## 2. P0 功能需求

### 2.1 MOD-AUTH

#### FR-AUTH-001 登录、登出、验证码

| 字段 | 内容 |
| --- | --- |
| 需求 ID / 名称 | `FR-AUTH-001` / 登录、登出、验证码 |
| 业务目标 | 让合法账号安全登录、获得与角色相符的会话，并能主动退出；阻止未认证访问业务功能。 |
| 来源与优先级 | 基线 BL-REQ-001 v1.2；若依已有能力；课程项目方案；**P0** |
| 使用角色与数据范围 | 全部角色（登录前无业务数据范围；登录后按角色授予） |
| 前置条件 | 账号已创建且处于启用状态；验证码服务、Redis/Valkey 可用；用户已打开登录页。 |
| 输入与校验规则 | 用户名、密码、验证码、验证码 UUID；登出请求。校验：三项必填；验证码在有效期内且匹配；账号未停用。 |
| 系统行为 | 校验验证码→校验账号密码→生成 JWT→加载角色/权限→记录登录日志→返回令牌；登出时清理服务端登录态。失败提示不得区分“账号不存在/密码错误”。 |
| 输出与结果 | 成功：令牌、用户基本信息、角色/权限标识；失败：统一错误提示和可重试状态；登出：当前会话失效。 |
| 异常情况与处理 | 验证码错误/过期→拒绝并刷新验证码；密码错误或账号停用→统一登录失败；连续失败达到若依配置阈值→按配置锁定/限制；缓存不可用→拒绝登录并提示稍后重试，不放行。 |
| 关联业务规则 | BR-AUTH-001、BR-AUTH-002、BR-AUTH-010、BR-AUTH-011；BR-STU-006、BR-TCH-007 |
| 验收标准 | `AC-FR-AUTH-001`：合法启用账号在验证码正确时登录成功并获得令牌；错误密码、停用账号、错误验证码均被拒绝；未登录访问受保护接口返回 401。 |
| 关联用例 / 数据 | `UC-AUTH-001` / `DR-AUTH-001` |

#### FR-AUTH-002 用户、角色、菜单、按钮权限配置

| 字段 | 内容 |
| --- | --- |
| 需求 ID / 名称 | `FR-AUTH-002` / 用户、角色、菜单、按钮权限配置 |
| 业务目标 | 让系统管理员按最小权限配置账号、角色、菜单和按钮权限，并让业务权限与若依 RBAC 对齐。 |
| 来源与优先级 | 基线 v1.2；若依 RBAC；D-014/D-018；**P0** |
| 使用角色与数据范围 | 系统管理员（SCOPE_SYSTEM） |
| 前置条件 | 系统管理员已登录；已明确业务角色与权限字符串命名空间。 |
| 输入与校验规则 | 账号、角色、菜单/按钮、权限字符串、启停状态。校验：权限字符串唯一且属于允许命名空间；角色代码唯一；菜单树无环；不得删除内置必要权限。 |
| 系统行为 | 维护角色与菜单/按钮关联；给账号分配一个或多个业务角色；保存后立即影响授权判断；所有变更记录操作日志。 |
| 输出与结果 | 账号获得/失去对应功能权限；越权请求被后端拒绝；权限配置可查询。 |
| 异常情况与处理 | 权限字符串冲突→拒绝；菜单父子成环→拒绝；删除仍被引用的角色/菜单→拒绝或要求先解绑；内置超级管理员配置→只允许初始化/应急使用，不用于验收。 |
| 关联业务规则 | BR-AUTH-007、BR-AUTH-010、BR-AUTH-011；BR-AUTH-001、BR-AUTH-008 |
| 验收标准 | `AC-FR-AUTH-002`：给账号分配“班主任”角色后只能进入班主任授权功能；移除角色后原令牌再次请求业务接口被拒绝；权限字符串冲突无法保存。 |
| 关联用例 / 数据 | `UC-AUTH-001` / `DR-AUTH-001` |

#### FR-AUTH-003 业务角色分配与账号绑定

| 字段 | 内容 |
| --- | --- |
| 需求 ID / 名称 | `FR-AUTH-003` / 业务角色分配与账号绑定 |
| 业务目标 | 把登录账号与唯一的学生/班主任业务档案关联，并分配业务角色，保证“账号身份”和“业务身份”可追溯。 |
| 来源与优先级 | 基线 v1.2；D-011；若依用户体系；**P0** |
| 使用角色与数据范围 | 系统管理员（SCOPE_SYSTEM）、教务管理员（SCOPE_ALL，限业务侧发起） |
| 前置条件 | 账号已存在或可创建；学生/班主任档案已存在；档案尚未绑定其他账号。 |
| 输入与校验规则 | 账号 ID、业务档案 ID（学生或班主任）、角色集合。校验：一个账号最多绑定一个学生或一个班主任；一个档案最多绑定一个账号；账号与档案类型匹配；角色与档案类型匹配。 |
| 系统行为 | 建立账号—档案关联；分配业务角色；保存后刷新该账号的可见范围；记录绑定/解绑审计。 |
| 输出与结果 | 账号登录后能解析出唯一学生/班主任身份；未绑定账号不能进入学生/班主任业务功能。 |
| 异常情况与处理 | 账号已绑定其他档案→拒绝并提示；档案已绑定其他账号→拒绝；学生档案绑定学生角色→拒绝；解绑时存在未完成业务→按规则阻止或要求先处理。 |
| 关联业务规则 | BR-STU-006、BR-TCH-007、BR-AUTH-004、BR-AUTH-007 |
| 验收标准 | `AC-FR-AUTH-003`：学生账号绑定学生档案后只能以该学生身份查询；同一档案不能绑定第二个账号；错误类型绑定被拒绝。 |
| 关联用例 / 数据 | `UC-AUTH-001` / `DR-AUTH-001` |

#### FR-AUTH-004 业务数据范围过滤

| 字段 | 内容 |
| --- | --- |
| 需求 ID / 名称 | `FR-AUTH-004` / 业务数据范围过滤 |
| 业务目标 | 在所有业务查询和写操作上执行角色+数据范围双重校验，防止水平/垂直越权。 |
| 来源与优先级 | 基线 v1.2；D-003/D-014/D-017/D-018；**P0** |
| 使用角色与数据范围 | 全部角色；范围按 SCOPE_SYSTEM/SCOPE_ALL/SCOPE_CLASS/SCOPE_SELF |
| 前置条件 | 用户已登录并具备目标功能权限；业务关系数据（班级、班主任、学生账号）已维护。 |
| 输入与校验规则 | 当前用户、功能权限、请求中的业务 ID/筛选条件。校验：功能权限必须命中；数据行必须落在当前用户范围；请求参数不能扩大范围。 |
| 系统行为 | 后端根据当前账号重新推导可访问范围；列表、详情、统计、导出、写操作使用同一范围；越权返回 403/404，不泄露其他数据存在性。 |
| 输出与结果 | 只返回授权范围内数据；写操作只作用于授权行；拒绝时给出无权限提示。 |
| 异常情况与处理 | 缺少班级/班主任关系→拒绝；前端隐藏但直接调接口→仍拒绝；批量/导出参数超范围→按范围过滤或拒绝；系统管理员请求成绩明细→拒绝。 |
| 关联业务规则 | BR-AUTH-001、BR-AUTH-002、BR-AUTH-004、BR-AUTH-005、BR-AUTH-006、BR-AUTH-008、BR-AUTH-009、BR-AUTH-012、BR-AUTH-013 |
| 验收标准 | `AC-FR-AUTH-004`：学生 A 无法读取学生 B 的成绩；班主任无法读取非本班数据；班主任只能处理本班；教务可看全校；系统管理员不能借审计日志展开成绩明细。 |
| 关联用例 / 数据 | `UC-AUTH-001` / `DR-AUTH-001` |

#### FR-AUTH-005 账号启停与密码重置

| 字段 | 内容 |
| --- | --- |
| 需求 ID / 名称 | `FR-AUTH-005` / 账号启停与密码重置 |
| 业务目标 | 让系统管理员安全地启停账号、重置密码，同时保留业务档案和历史数据。 |
| 来源与优先级 | 基线 v1.2；若依账号管理；D-011；**P0** |
| 使用角色与数据范围 | 系统管理员（SCOPE_SYSTEM） |
| 前置条件 | 目标账号存在；操作人具备账号管理权限；重置密码时能安全传递临时密码。 |
| 输入与校验规则 | 账号 ID、启停动作、重置密码请求。校验：不得停用当前唯一可用的系统管理员；不得停用内置初始化账号到无法恢复；临时密码符合若依密码策略。 |
| 系统行为 | 启停账号；重置密码并标记首次登录需修改（若若依支持）；记录操作日志；停用后现有会话失效或后续请求被拒绝。 |
| 输出与结果 | 账号状态更新；停用账号不能登录；密码重置后旧密码失效；业务档案和历史数据保留。 |
| 异常情况与处理 | 停用自己导致无管理员可用→拒绝；账号不存在→拒绝；重置密码不符合策略→拒绝；停用后仍持有旧令牌→后续请求拒绝。 |
| 关联业务规则 | BR-AUTH-001、BR-AUTH-011；BR-STU-006、BR-TCH-007 |
| 验收标准 | `AC-FR-AUTH-005`：停用账号后无法登录且旧令牌不能访问业务接口；重新启用后可登录；重置密码后旧密码失败、新密码成功。 |
| 关联用例 / 数据 | `UC-AUTH-001` / `DR-AUTH-001` |

### 3.1 P1 边界说明

- 复核（`MOD-REVIEW`）不阻塞 P0；P0 的教务更正不是复核，二者不能共用“复核”状态名。
- Excel 导入/导出（`MOD-IMPORT`）不改变 P0 手工录入；P1 只允许草稿/退回任务导入，不覆盖已提交/发布。
- 趋势（`MOD-TREND`）和班级对比（`MOD-COMPARE`）只使用已发布、同口径数据；P0 只做单场考试基础统计。
- P1 的 11 项功能均有 `FR-*` 编号和验收摘要，但**不进入 P0 退出条件**。
