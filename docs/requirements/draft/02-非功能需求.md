# 02 非功能需求

> 项目：高中学生信息与成绩管理系统  
> 基线：`BL-REQ-001 v1.2-provisional`  
> 文档版本：`v0.2-draft`  
> 状态：**第 2 阶段非功能需求初稿，待用户/小组审核**  
> 日期：2026-10-28  
> 说明：所有指标均为**课程实验建议验收目标**，除特别注明外尚未实测；不得把本文指标写成“已通过”。

## 0. 写法与证据边界

1. 每条 NFR 采用“场景—指标—测量条件—验收方式”结构。
2. 指标是**需求目标**，不是测试结果；未执行测试的条目状态为“未验证”。
3. 课程项目没有真实学校生产数据、压测环境和 7×24 运维，因此不承诺未经验证的可用性/容灾数字。
4. 性能指标使用“课程实验建议目标”，在后续测试阶段可用合成数据复现；如果环境不同，应记录实际环境而不是改写成“已达标”。
5. 安全、隐私、审计要求即使没有自动化测试，也必须能通过代码审查、权限矩阵和手工越权用例验证。

## 1. 性能与响应时间

### NFR-PERF-001 学生本人成绩查询

| 项目 | 内容 |
| --- | --- |
| 场景 | 学生对本人已发布成绩进行列表/详情查询 |
| 指标 | 在课程实验建议数据规模下，50 个并发学生查询，95% 请求 ≤ 2 秒，99% ≤ 5 秒；无请求超过 10 秒 |
| 测量条件 | 单机开发/实验环境；1 所学校、3 个年级×10 个班×50 名学生（约 1500 名学生）、6 科、3 次考试、已发布合成数据；浏览器到后端完整链路；不含首次冷启动 |
| 验收方式 | 使用可复现脚本压测并保存环境、数据量、并发数、P50/P95/P99；未实测则标记“未验证” |
| 说明 | 数值为课程实验建议目标，不是生产 SLA |

### NFR-PERF-002 成绩保存与提交

| 项目 | 内容 |
| --- | --- |
| 场景 | 班主任保存草稿或提交一个班级×科目任务（约 50 名学生） |
| 指标 | 20 个并发班主任操作，95% 保存/提交 ≤ 3 秒；提交失败必须返回明确原因，不能长时间无响应 |
| 测量条件 | 单机实验环境；50 名学生×6 科的任务数据；含服务端校验、事务和审计写入；不含网络异常重试 |
| 验收方式 | 并发保存/提交脚本；检查响应时间、事务结果、审计记录；未实测标记“未验证” |
| 说明 | 课程实验建议目标；若数据库/缓存环境不同，记录实际值 |

### NFR-PERF-003 统计与排名

| 项目 | 内容 |
| --- | --- |
| 场景 | 教务/班主任查看单场考试单班单科统计或班级总分排名 |
| 指标 | 单班单科统计 95% ≤ 3 秒；班级总分排名 95% ≤ 5 秒；统计口径计算正确 |
| 测量条件 | 50 名学生×6 科×3 次考试的合成数据；单机实验环境；并发 10 个统计请求 |
| 验收方式 | 统计接口/页面计时 + 手工核对分母、缺考、排名结果；未实测标记“未验证” |
| 说明 | 不承诺大数据仓库级性能 |

## 2. 安全与个人信息保护

### NFR-SEC-001 认证与授权

| 项目 | 内容 |
| --- | --- |
| 场景 | 未登录访问、越权访问、直接改 URL/ID、前端隐藏按钮后直接调接口 |
| 指标 | 受保护接口 100% 要求认证；越权测试矩阵 100% 返回 403/404；不得返回超范围数据 |
| 测量条件 | 四类角色测试账号；学生 A/B、班主任 A/B、教务、系统管理员；覆盖列表、详情、统计、导出、写操作 |
| 验收方式 | 执行 `02-角色权限矩阵` 的越权测试；保留请求/响应证据；未执行不得标记通过 |
| 说明 | 前端隐藏不作为安全措施；后端必须重新推导数据范围 |

### NFR-SEC-002 密码与账号安全

| 项目 | 内容 |
| --- | --- |
| 场景 | 登录、密码存储、账号停用、密码重置 |
| 指标 | 密码不以明文存储/输出；停用账号不能登录且旧令牌后续请求被拒绝；重置后旧密码失效；登录失败提示不泄露账号是否存在 |
| 测量条件 | 若依现有密码策略/BCrypt；浏览器与接口测试；检查日志和响应不含明文密码 |
| 验收方式 | 代码/配置审查 + 登录/停用/重置测试；未执行标记“未验证” |
| 说明 | 不引入自建密码体系；复用若依安全机制 |

### NFR-SEC-003 个人信息最小化与脱敏

| 项目 | 内容 |
| --- | --- |
| 场景 | 学生档案、班主任档案、日志、导出、审计查看 |
| 指标 | P0 不收集身份证号、家庭住址、家长电话；页面/日志/导出不出现明文敏感字段；系统管理员审计视图不展开成绩明细 |
| 测量条件 | 数据字典字段清单；页面/导出/日志抽样；权限矩阵中的系统管理员/班主任视图 |
| 验收方式 | 字段清单核对 + 页面/日志/导出检查；未执行标记“未验证” |
| 说明 | 如老师要求完整学籍字段，需单独评审并补充隐私规则 |

## 3. 可靠性与数据一致性

### NFR-REL-001 事务一致性

| 项目 | 内容 |
| --- | --- |
| 场景 | 成绩提交、审核、发布、撤回、更正、复核更正 |
| 指标 | 关键写操作原子生效：要么全部成功，要么全部回滚；不出现“成绩改了但审计没写”“部分学生保存成功、部分失败” |
| 测量条件 | 正常流程 + 模拟审计写入失败/数据库异常；检查业务数据与审计记录 |
| 验收方式 | 故障注入/事务测试；未实测标记“未验证” |
| 说明 | 审计与业务同事务，见 `BR-AUDIT-005` |

### NFR-REL-002 并发与幂等

| 项目 | 内容 |
| --- | --- |
| 场景 | 同一班主任两个会话同时编辑、重复提交、重复发布、重复导入 |
| 指标 | 并发保存不静默覆盖；版本冲突返回明确提示；重复提交/发布不产生重复版本；导入全成功或全失败 |
| 测量条件 | 两个会话同时保存；重复点击提交/发布；P1 导入重复文件 |
| 验收方式 | 并发/重复操作测试；检查版本号、审计和最终数据；未实测标记“未验证” |
| 说明 | 使用版本号/乐观锁（实现阶段确定技术细节，但需求要求可观察行为） |

### NFR-AVAIL-001 课程演示窗口可用性

| 项目 | 内容 |
| --- | --- |
| 场景 | P0 主链路演示/验收的受控时间段 |
| 指标 | 课程实验建议：连续 2 小时演示窗口内无计划外停机；若单次故障，10 分钟内恢复到可演示状态；已提交数据不丢失 |
| 测量条件 | 单机实验环境；合成数据；不模拟生产级容灾/多活；不承诺 7×24 |

## 8. 权限与审计

### NFR-AUD-001 审计完整性与不可篡改

| 项目 | 内容 |
| --- | --- |
| 场景 | 成绩修改、提交、退回、通过、发布、撤回、更正、复核关键节点 |
| 指标 | 关键事件 100% 有审计记录；记录包含前后值、原因、操作人、角色、时间、版本；业务界面不能修改/删除审计；审计失败则业务失败 |
| 测量条件 | 主链路 + 异常路径；检查审计与业务数据一致性 |
| 验收方式 | 审计覆盖清单 + 事务故障测试；未实测标记“未验证” |
| 说明 | 若依通用操作日志不能替代业务变更记录 |

### NFR-AUD-002 审计可见性与最小权限

| 项目 | 内容 |
| --- | --- |
| 场景 | 教务、系统管理员、班主任查看审计 |
| 指标 | 教务看业务审计；系统管理员只看系统/安全审计元数据，不能展开/导出成绩明细；班主任只看本班相关；学生不可见 |
| 测量条件 | 四类角色分别访问审计列表/详情/导出 |
| 验收方式 | 权限矩阵越权测试；未执行标记“未验证” |
| 说明 | 审计权限不能成为成绩明细的旁路 |
