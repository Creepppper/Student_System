## 3. 视觉与可读性

- 统一 1600×900 桌面视口；截图高 1800px（2×），文字在 Word 中清晰。
- 主内容采用 232px 深色侧栏 + 白色工作区 + 卡片；信息层级为“页面标题→筛选→表格/详情→分页”。
- 状态标签颜色：
  - 绿色：批准/已发布/在读/成功；
  - 蓝色：提交/待审核/普通；
  - 橙色：退回/缺考/待指派；
  - 红色：错误/未录入/风险；
  - 紫色：P1 规划。
- 少量页面底部留白（UI-02/03/04 等）是为了保持 16:9 截图统一；不表示功能缺失。
- UI-03A/04A/06A/06B/06C 弹窗均完整落入 1600×900 视口。

## 4. 已知限制

1. **静态原型**：筛选/查询/提交/审核/发布等按钮不写真实数据；页面状态通过 URL 参数切换。
2. **登录非真实认证**：不产生 Token/JWT/会话。
3. **无数据库/API**：所有姓名、成绩、审计记录为虚构演示数据。
4. **P1 是规划**：UI-09/10/10A 不代表后端完成；不进入 P0 退出条件。
5. **未做移动端**：按桌面 1600×900 设计；不覆盖手机/平板。
6. **Word 最终排版未验证**：建议先插 UI-05/06/07/08A/08B，其他放附录；超大页面横向。
7. **截图为视口截图**：不使用整页长截图，以保证统一比例；页面内容均落在正式截图中。
