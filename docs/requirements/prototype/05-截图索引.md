## 4. 使用建议

- 正文优先插入 UI-05、UI-06、UI-07、UI-08A/08B：能直接支撑成绩规则、审核发布、个人权限和审计边界；
- UI-02A/03A/04A/06A/06B/06C 可放在附录“界面原型补充”；
- P1 三张图必须放在“P1 扩展/待确认”章节，不能与 P0 截图混列；
- Word 单栏建议 15～16cm 宽；超大页面可横向。
