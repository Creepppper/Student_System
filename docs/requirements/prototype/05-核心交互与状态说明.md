# 05 核心交互与状态说明

> 本文件说明原型中“看起来可操作”的状态和演示逻辑；所有数据均为虚构，不连接真实接口。

## 1. 登录与权限展示

- `?view=login&state=error`：展示验证码错误的提示；账号/密码为演示占位。
- 登录页展示四类角色；角色差异主要通过进入页面后的左侧菜单和操作权限体现。
- 原型不做真实认证；不写 Token、Cookie 或会话。
- 教务页面无“审核自己提交任务”的入口；系统管理员页面无成绩明细入口。

## 2. 查询筛选

学生、考试、审核、统计、审计页面均使用统一筛选卡：

- 查询：静态展示筛选结果（不调用 API）；
- 重置：清空/恢复默认条件的视觉占位；
- 分页：展示分页控件和条数；
- 页面状态通过 URL 参数切换，便于批量截图。

## 3. 成绩录入状态

| 状态 | URL | 界面表现 |
| --- | --- | --- |
| 正常录入 | `?view=grades` | 8/8 已录入；缺考 1 人；真实零分 1 人；按钮“提交审核”可用 |
| 校验错误 | `?view=grades&state=invalid` | 陈星宇 105.0 超满分红框；周子轩未录入；提交按钮禁用并标“校验未通过” |
| 退回重提 | `?view=grades&state=returned` | 黄色退回提示；任务 `TASK_RETURNED`；可修改后重新提交 |

规则的可视化：

- 缺考：单元格显示“缺考”，不显示 0，统计口径“不计入分母/排名”；
- 未录入：空单元格 + 红色“未录入”，阻止提交；
- 真实零分：显示 `0.0` + 绿色“真实零分”，参与统计；
- 0.5 步长、满分 100 的提示常驻；105.0 被标红；
- 提交后锁定、退回后重提在 UI-05A/05B 的说明中体现。

## 4. 审核与发布状态

| 界面 | 状态/操作 |
| --- | --- |
| UI-06 | 任务列表同时出现 `TASK_SUBMITTED`、`TASK_APPROVED`、`TASK_RETURNED`；右侧详情展示 8/8、职责分离、`PUB_UNPUBLISHED` |
| UI-06A | 退回原因必填；说明退回只改任务状态，不改成绩；班主任重提后必须再次审核 |
| UI-06B | 班级发布前检查 6 个适用科目全部 `TASK_APPROVED`、无未录入；版本 v1 |
| UI-06C | 发布版本 v1/v2；撤回后不可见，重发版本+1；受控更正保持 `PUB_PUBLISHED`，生成新版本并写审计 |

**不把 `TASK_APPROVED` 显示为 `PUB_PUBLISHED`**：前者是任务状态，后者是班级发布状态。

## 5. 学生查询状态

- `?view=query`：只显示陈星宇本人 6 科成绩、总分 521.0、班级排名第 3；无他人信息。
- `?view=query&state=unpublished`：显示“该考试成绩尚未发布”，不回显旧分数，提示未发布/已撤回不可见。
- 缺考不显示 0；未录入不参与总分；页面不显示班级平均/年级排名。

## 6. 统计与审计

- `?view=stats`：班主任本班统计；有效人数 41、均分 512.6、最高 579.0、完整率 97.6%；缺考单列；只有完整总分参与排名。
- `?view=stats&role=academic`：教务全校统计；参考班级 42、有效学生 1,680、班级汇总和口径说明；无班级好坏评价。
- `?view=audit`：教务业务审计，显示前后值、版本、原因、操作人；前后值为虚构数据。
- `?view=audit&role=sys`：系统管理员脱敏视图，不显示成绩前后值/明细，不能展开/导出成绩；强调系统管理≠教务审批。

## 7. P1 复核

- `?view=review-apply`：学生选择本人已发布成绩、填写理由、提交申请；显示 `REV_PROCESSING` / `REV_NO_CHANGE`。
- `?view=review-process`：班主任受理/核查本班申请；核查意见三选一；不直接改分。
- `?view=review-final`：教务最终确认/驳回/受控更正；更正生成新版本 v2 并写审计。
- P1 页面统一紫色标识，明确不进入 P0 退出条件。

## 8. 交互限制

- 查询、重置、导出、提交、审核、发布、撤回、更正按钮的**点击不一定改变数据**；原型重点展示界面状态。
- 弹窗通过 `?modal=` 直接呈现，保证可复现截图。
- 没有真实 API 调用、数据库写入、文件上传或消息队列。
- 页面刷新后状态回到 URL 参数指定的演示状态。
