# 05 界面设计说明

## 1. 原型目标与边界

本阶段交付**可编辑 HTML/CSS/JS 静态原型**和**真实 Chrome 渲染截图**，用于插入实验一《需求规格说明书》。

- 不开发真实业务系统；
- 不连接 MariaDB、Valkey 或真实 API；
- 不做真实登录认证；
- 不修改 Java、Vue3 正式前端、SQL、若依配置；
- 不使用 Axure RP，不生成 `.rp`；不使用 Figma/云端设计工具。

## 2. 打开方式

原型入口：`docs/requirements/prototype/index.html`。

推荐本地静态服务（避免浏览器 file 安全策略差异）：

## 3. 设计系统

| 项 | 约定 |
| --- | --- |
| 基准视口 | 1600×900；截图 `--force-device-scale-factor=2`，输出 3200×1800 |
| 字体 | `Noto Sans CJK SC`、`Source Han Sans SC`、`Microsoft YaHei` 回退 |
| 主色 | 蓝色 `#2f6fed`，用于主按钮、当前菜单、链接 |
| 成功/警告/危险 | `#18a058` / `#d98b0b` / `#d64545` |
| P1 色 | 紫色 `#7c4dff` + 浅紫底 `#f4f0ff` |
| 背景 | 页面 `#f5f7fb`，卡片白色，边框 `#e6eaf0` |
| 布局 | 232px 深色侧栏 + 64px 顶栏 + 内容区；内容区 20/24px 内边距 |
| 组件 | 筛选区、数据卡片、表格、状态标签、分页、弹窗、表单、提示条、空状态 |
| 字号 | 页面标题 21px，卡片标题 13px，正文/表格 11.5～12px，辅助文字 9.5～10.5px |
| 交互 | 原型只做查询/重置/弹窗入口的静态演示；业务提交不落库 |

## 4. 统一布局

所有后台页面（除登录）使用同一壳层：

1. 左侧：品牌、当前学年、按角色显示的功能菜单、原型声明；
2. 顶栏：面包屑、页面名、通知、角色胶囊；
3. 内容：页面标题/说明、页面级操作、筛选卡、表格或双栏详情、分页；
4. 弹窗：居中、遮罩、标题/说明、表单、底部操作。

角色菜单差异：

- **教务**：学生信息、班主任与班级、考试管理、成绩审核与发布、成绩统计、业务变更记录、P1 复核最终确认；
- **班主任**：成绩录入、本班成绩统计、P1 复核受理与核查；
- **学生**：本人成绩查询、P1 成绩复核申请；
- **系统管理员**：审计摘要（脱敏）；不显示成绩明细与教务审批。

任课教师入口、任教关系、按科目分配教师均不存在。

## 5. 页面视觉原则

- 登录页采用左品牌/右表单的双栏，不出现真实校徽或敏感信息；
- 管理页以表格为主，查询条件在上、操作在右、状态标签在数据行内；
- 成绩录入页把“分数输入/状态/统计口径”放在同一行，缺考、未录入、真实零分用不同标签和文案；
- 审核页左右分栏：左侧任务列表，右侧审核详情/发布状态；
- 统计页用轻量 CSS 柱状图，不使用第三方图表库；
- P1 页面统一紫色规划标识，不冒充 P0 已完成功能。
