# 05 表单字段及校验规则

> 本文件按原型页面列出字段和**界面层**校验提示；真实后端校验、权限与事务仍以需求/设计为准，本原型不连接数据库。

## 1. 登录

| 字段 | 类型/展示 | 校验/提示 |
| --- | --- | --- |
| 账号 | 文本 | 必填；演示值 `academic01` |
| 密码 | 密码 | 必填；演示值掩码 |
| 验证码 | 文本 + 图形码 | 必填；`state=error` 显示“验证码不正确，请重新输入” |
| 记住账号 | 复选框 | 仅展示 |

不实现真实认证、JWT、Token 或验证码服务。

## 2. 学生信息

| 字段 | 校验/展示 |
| --- | --- |
| 学号 | 只读/唯一；编辑提示“不允许物理删除后重建” |
| 姓名 | 必填 |
| 性别 | 下拉 |
| 学籍状态 | 在读/休学/转出；表格用状态标签 |
| 当前班级 | 只读；变更使用“归属变更”，不直接覆盖历史 |
| 账号绑定 | 只读展示；学生账号≠学生档案 |
| 班级归属历史 | 展示学年/班级/起止/当前有效；历史不可覆盖 |

## 3. 班主任与班级

| 字段 | 校验/展示 |
| --- | --- |
| 当前班主任 | 只读；每班同一时刻最多 1 名有效 |
| 新班主任 | 必选 |
| 生效日期 | 必填；变更后原任职结束、新任职生效 |
| 变更原因 | 必填；写审计 |
| 任职历史 | 只读；保留原记录 |

不出现任课教师、按科目分配教师或任教关系字段。

## 4. 考试

| 字段 | 校验/展示 |
| --- | --- |
| 考试名称 | 必填；同一学年/学期不重名（界面提示） |
| 考试类型 | 期中/期末/单元 |
| 学期 | 下拉 |
| 考试时间 | 起止时间；倒置不允许（界面提示） |
| 参与年级/班级 | 至少 1 个班级 |
| 适用科目/满分 | 至少 1 科；满分 > 0；优秀线≥及格线；0.5 分步长 |
| 状态 | 新建为 `EXAM_DRAFT`；开放后 `EXAM_OPEN`；结束/归档独立 |

考试状态与成绩发布状态**分列**；`EXAM_OPEN` 不表示已发布。

## 5. 成绩录入

| 字段/动作 | 校验/展示 |
| --- | --- |
| 考试 | 只读上下文，须 `EXAM_OPEN` |
| 班级 | 当前班主任本班 |
| 科目 | 本班全部适用科目 |
| 学生名单 | 任务花名册；不显示其他班 |
| 分数 | 0.5 步长；0～满分；0 是有效真实零分；缺考不带分数 |
| 未录入 | 阻止提交；列学生；不得自动转 0 |
| 暂存 | 保存草稿（视觉占位） |
| 提交审核 | 需 8/8 正常或缺考；`TASK_DRAFT`/`TASK_RETURNED` 可提交 |
| 退回后重提 | 显示退回原因；修改后重新提交并再次审核 |

## 6. 审核/发布

| 字段/动作 | 校验/展示 |
| --- | --- |
| 待审核任务 | 显示任务编号/班级/科目/提交人/状态/均分 |
| 审核通过 | 只能由教务；审核人≠提交人；状态变 `TASK_APPROVED` |
| 退回原因 | 必填；状态变 `TASK_RETURNED`；班主任重提 |
| 班级发布 | 全部适用任务 `TASK_APPROVED`；无未录入；至少 1 科；版本 v1 |
| 撤回原因 | 必填；`PUB_WITHDRAWN`；学生不可见、数据保留 |
| 更正原因/前后值 | 必填；保持 `PUB_PUBLISHED`；生成新版本 v2；重算总分/排名；审计 |

## 7. 学生查询

只读本人已发布数据；不提供编辑字段。缺考显示“缺考”，未录入不显示，撤回不显示旧值。总分/排名只在完整时显示。

## 8. P1 复核

| 字段 | 校验/展示 |
| --- | --- |
| 考试/科目 | 只能选本人已发布成绩 |
| 复核理由 | 必填 |
| 申请状态 | `REV_PENDING`/`REV_PROCESSING`/`REV_NO_CHANGE`/`REV_CORRECTED`/`REV_REJECTED`/`REV_WITHDRAWN` |
| 班主任核查意见 | 无需修改/建议更正/建议驳回；不直接改分 |
| 教务最终结论 | 无需更正/更正/驳回；更正生成新版本并审计 |
| 申请截止 | 发布后 5 个工作日（课程模拟） |
