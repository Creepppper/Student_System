## 3. 关键需求覆盖

- 四类角色均有页面；左侧菜单按角色变化，未出现任课教师入口。
- 班主任成绩页覆盖正常、非法/未录入、退回重提；缺考/未录入/真实零分三态视觉区分。
- 教务审核页把 `TASK_*` 与 `PUB_*` 分列；退回、发布、撤回/更正都有对应界面。
- 学生成绩页只出现本人信息；未发布状态不回显旧值。
- 系统管理员审计页不显示成绩前后值；教务业务审计页才显示前后值。
- P1 页面统一加紫色 `P1 · 规划功能` 标识，并提示不进入 P0 退出条件。
