# 必要图表与参考来源清单

> 状态：绘图计划，不包含正式图表。图表将在范围评审后统一绘制。

## 1. 绘图原则

- 每张图回答一个需求问题，并引用相同的需求 ID、角色、数据和状态术语。
- 分析图描述“做什么”和业务关系，不画 Controller、Service、Mapper、Vue 组件等设计构件。
- 没有业务确认的关系用“待确认”标注，不画成既定事实。
- 逻辑关联与物理外键分开；需求阶段的 ER／概念模型不宣称数据库已经实现。
- 原创重绘，只参考公开资料的组织思路；不复制无许可证仓库的正文和图像。
- Mermaid 可用于版本管理，最终 Word 中若需插图，应导出清晰 SVG/PNG 并检查中文字体和打印效果。

## 3. 图表的建议内容

### FIG-01 系统上下文图

候选外部实体：学生、任课教师／班主任、教务管理员、系统管理员。候选数据流：身份凭据、基础资料维护信息、考试配置、成绩录入／审核结果、已发布成绩、复核申请／处理结果。

数据库和 Valkey 是系统内部技术构件，不作为业务上下文图的外部实体。只有真实存在的校外系统才作为外部系统 Actor。

### FIG-02 1 层 DFD

候选过程：

1.0 管理基础资料  
2.0 管理考试  
3.0 录入与提交成绩  
4.0 审核与发布成绩  
5.0 查询与统计成绩  
6.0 处理成绩复核

候选数据存储：组织与人员、任教关系、考试、成绩、复核、业务审计。是否拆分需由最终概念模型决定，不能直接照搬数据库表名。

### FIG-03 总用例图

只保留能给 Actor 产生完整结果的用例，如“维护学生档案”“录入成绩”“审核并发布成绩”“查询本人成绩”“申请成绩复核”。登录和权限校验可作为公共前置条件或被包含用例，不把每个按钮画成用例。

### FIG-05 领域概念类图

候选概念：学年、学期、年级、班级、学生、教师、科目、任教关系、考试、考试科目、成绩、成绩批次／提交、复核申请、业务审计。若依的 `SysUser`、`SysRole` 可在边界说明中体现身份映射，但不应让技术账号模型淹没业务概念。

### FIG-06 状态图

建议围绕“考试班级成绩批次”而非单个分数字段建模。候选状态：草稿、已提交、已退回、审核通过、已发布、已撤回／已更正。最终状态名和转换权限必须先回答 Q-005、Q-006、Q-040 至 Q-049。

### FIG-08 复核时序图

只画一个最复杂且跨角色的场景：学生提交 → 系统校验 → 处理人受理 → 核查 → 无误结案或更正成绩 → 重新计算／发布 → 学生查看结果。它用于验证用例是否遗漏异常路径，不用来描述 Spring Controller 方法调用。

## 4. 条件性图表

| 图表 | 何时才画 | 当前意见 |
| --- | --- | --- |
| 决策表／决策树 | 排名、缺考、发布条件存在多条件组合时 | 规则确认后选一张，不必两种都画 |
| 分角色子用例图 | 总用例图拥挤或老师明确要求三端图时 | 最多拆为管理端、教师端、学生端 |
| 原型页面流程图 | 实验一明确要求 Axure 页面和页面跳转时 | 等原始任务书补齐 |
| 网络拓扑／部署图 | 实验一模板明确要求运行环境图时 | 更偏概要设计，SRS 中通常只需上下文和运行环境说明 |
| 协作图 | 老师指定或顺序图无法表达链接关系时 | 与顺序图信息重复，默认不画 |
| 组件图 | 进入概要设计后 | 不属于当前需求调研交付 |
| 数据库物理 ER 图 | 表结构评审完成后 | 当前只做概念／逻辑关系，不宣称物理外键 |

## 5. 不建议照搬的图表

- R4 中“所有 UML 图种各画一张”的作业式集合：数量大但与需求验证未必形成闭环。
- R2 的大型综合类图：本项目应拆出核心概念，保证可读性。
- 旧 V1.0 的网络拓扑、用户继承关系和不存在的 11 张占位图：需按新范围重新论证。
- R3 的 Enrollment／Credits／75% 出勤门槛模型：属于大学课程注册语义。
- R5 的多租户、收费、证书、工作流、AI 等模块依赖图：超出范围。

## 6. 图表到需求的验证清单

每张正式图完成后检查：

1. 名称是否与术语表和需求正文完全一致。
2. 每个 Actor 是否至少关联一个用例，每个用例是否能追踪到 `FR-*`。
3. DFD 上下层是否平衡，数据流是否在数据字典中定义。
4. 概念类／ER 的基数是否有业务依据，是否误把逻辑关系写成物理外键。
5. 状态图每个转换是否有触发事件、权限和失败处理。
6. 顺序图是否来自已批准用例，而不是虚构接口。
7. 图中是否混入未来功能或已排除功能。
8. 图表是否有编号、标题、来源／原创说明和正文引用。
