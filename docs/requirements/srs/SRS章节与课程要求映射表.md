## 4. 与建议目录的差异

| 建议目录项 | 本稿处理 | 原因 |
| --- | --- | --- |
| 独立“外部接口需求”章 | 合并进 2.6 运行环境、4.2 权限、6.1 兼容性 | 课程项目接口主要是浏览器/若依基础；避免把 Controller/URL 写成需求 |
| 独立“产品提交”章 | 放在文档控制/附录 F | 未找到老师提交规范；不编造交付清单 |
| 独立“数据字典”附录 | 5.3 核心字典 + 引用完整 DR 文档 | 避免复制 17 个对象的全部属性造成漂移 |
| 每用例一张顺序图 | 只保留 FIG-08 P1 时序 + 关键活动/状态 | 课件不要求所有用例都画；避免堆图 |
| 访谈/问卷记录 | 不提供 | 未执行真实访谈；不伪造证据 |
| 评审签字 | 不提供 | 尚未正式评审；不伪造签字 |

## 5. 结论

本 SRS 已覆盖课件明确要求的需求描述、分析模型、功能/非功能/数据需求、验证与追踪；对原始实验一任务书、页数/模板、真实用户确认等**未核实事项**保持显式标记。后续 5B-2 排版不得改变本映射中的业务范围与计数。
